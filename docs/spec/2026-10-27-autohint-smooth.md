# ТЗ: автохинтер со сглаженной целью и предпочтение файла с родными инструкциями

- **Идентификатор:** `2026-10-27-autohint-smooth`
- **Дата:** 2026-10-27
- **Статус:** утверждено постановкой владельца 2026-10-27 («Делай оба» — после разбора скриншота примера виджетов против Блокнота)
- **Основа:** ADR-0002 (`Target::Mono` обоснован на PT Mono с родными TrueType-инструкциями), ADR-0017 (выбор файлов семейства: пути сортируются, первый Regular побеждает); факты разбора 2026-10-27: пример виджетов на `Cascadia Mono` взял `CascadiaMono-Regular.otf` (CFF, инструкций нет) вместо `CascadiaMono-Regular.ttf` (3 581 байт инструкций), потому что `.otf` < `.ttf` при сортировке; для CFF `hinting_engine` даёт автохинтер, а автохинтер skrifa в `Target::Mono` (аналог `FT_LOAD_TARGET_MONO`, «только для алиасной монохромной растеризации») привязывает стойки по обеим осям и расширяет их до 2 px — текст выглядит как грубый битмап. У шрифта репозитория RobotoMono (инструкций нет → автохинтер) то же: при 16 px `С` сжата до 8 колонок из 10, стойка `к` 2 px.

## 1. Цель

Текст на шрифтах без родных инструкций (CFF, неинструктированные TTF, в том числе шрифт репозитория) растеризуется автохинтером в сглаженном режиме: стойки целой ширины 1 px на своих местах, пропорции букв сохранены. Для семейства, установленного и как TrueType с инструкциями, и как CFF, берётся файл с инструкциями — он хинтуется интерпретатором, как было задумано в ADR-0002.

## 2. Границы

**Входит:**
1. `font.rs`: при выборе файла начертания в `from_faces` среди файлов одного стиля предпочитается тот, чьи глифы несут родные инструкции (`maxp.maxSizeOfInstructions > 0`); среди равных — прежний порядок (путь/список). Признак вычисляется один раз при сборке семейства общей функцией, которой пользуется и `hinting_engine` в `rasterizer.rs` (одно определение «есть родные инструкции»).
2. `rasterizer.rs`: `build_states` — цель хинтинга зависит от движка: интерпретатор — `Target::Mono` (как раньше), автохинтер — `Target::Smooth { mode: Normal }` (умолчание FreeType `FT_LOAD_TARGET_NORMAL`: ширина стоек приводится к целым пикселям, положение не привязывается).
3. Тесты в `tests/stage2_font.rs`: (а) `from_faces` выбирает файл с инструкциями независимо от порядка — на копии Regular с правленым полем `maxp.maxSizeOfInstructions` (тот же приём, что `with_narrow_i`); (б) растр автохинтера совпадает с прямым рендером `skrifa` (`Engine::Auto`, `Smooth/Normal`) и отличается от `Mono` — тест ловит откат к прежней цели; (в) golden `soft_golden_{16,32}px.bin` перезаписываются (`GTERM_UPDATE_GOLDEN=1`), различие описывается в отчёте; `stage4_gl` identical.
4. ADR-0025, ТЗ 1.20 (FR-8.4 — цель хинтинга по движку; FR-8.1/ADR-0017 — предпочтение файла), `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`, отчёты `done`/`test`/`verify`.

**Не входит:** режим `Light`, LCD-сглаживание, гамма-коррекция смешивания, дробная ширина ячейки, паритет с ClearType Блокнота; изменение пути интерпретатора (шрифты с инструкциями рендерятся байт в байт как раньше); коллекции `.ttc`.

## 3. Контракты

- Выбор файла — только на сборке семейства (`load`/`from_files`/`system*` через `from_faces`); горячий путь кадра не затронут (NFR-6), `unsafe` нет (NFR-9).
- GL ↔ Software бит-идентичны (атлас общий; §8).
- Для файла с инструкциями растр не меняется: цель `Mono` и интерпретатор прежние.
- Подстановка начертаний (ADR-0003) не меняется: предпочтение действует внутри одного стиля.

## 4. Критерии приёмки

| № | Критерий | Чем подтверждается |
|---|---|---|
| К1 | Среди двух Regular побеждает файл с инструкциями при любом порядке | новый тест (а) |
| К2 | Автохинтер работает в `Smooth/Normal`: растр = прямой рендер skrifa, ≠ `Mono` | новый тест (б) |
| К3 | Путь интерпретатора не изменён | diff `build_states`: ветка `Interpreter` → `Mono`; прогон примера виджетов на `Cascadia Mono` берёт `.ttf` |
| К4 | GL ↔ Software identical после перезаписи golden | `stage4_gl`, `stage3_render golden` |
| К5 | Пример виджетов: стойки 1 px, пропорции букв как в файле | дамп растра `Сек` 14 px до/после; глазами — владелец |
| К6 | Гейты, размер, документы | fmt, clippy, test; размеры release; ADR-0025, ТЗ, `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md` |

## 5. Риски

- Шрифт репозитория и все golden меняются: прежние эталоны не воспроизводимы без отката цели — принято, эталон перезаписывается осознанно.
- В `Smooth/Normal` часть стоек остаётся на дробных позициях (серые края с обеих сторон) — цена сохранения пропорций; `Light` отклонён (стойка на полпикселя размывается в две серые колонки при 16 px).
- Семейство, где файл с инструкциями не Regular (например, инструктирован только Bold), получит разные движки по начертаниям — как и до задачи.
