# ТЗ: режим псевдографики (процедурная / шрифт / комбинированная) и пример `pseudographica`

- **Идентификатор:** `2026-10-23-box-drawing-mode`
- **Дата:** 2026-10-23
- **Статус:** утверждено владельцем 2026-10-23 (О1 — отдельный путь `set_box_drawing_mode` на атласе и бэкендах, О2 — системный шрифт; логический размер шрифта примера — 11 px)
- **Основа:** ТЗ FR-8.4 (псевдографика рисуется процедурно и перекрывает шрифт), FR-9, FR-13, FR-25, FR-28; ADR-0002 (процедурная псевдографика), ADR-0004 (`AppHandler`, `Request`), ADR-0017 (пример без `assets/`); код `rasterizer.rs` (`rasterize`, `is_style_independent`), `atlas.rs` (`set_size`, `clear_page`), `gl_backend.rs`/`soft_backend.rs` (`set_size`), `app/events.rs` (`apply_request`).

## 0. Текущее состояние (факты, по коду)

- Порядок источников глифа в `Rasterizer::rasterize` (`rasterizer.rs:190–193`): SVG → `box_drawing::draw` для U+2500–U+259F → контур шрифта. Процедурный путь безусловный: глифы рамок из шрифта никогда не используются.
- `Rasterizer::is_style_independent` (`:104`) считает псевдографику одинаковой во всех начертаниях — атлас заполняет четыре канала сразу (`atlas.rs:277`).
- Смена растеризации на лету уже есть для DPI: `Atlas::set_size` → `clear_page` (сброс страницы, `resets += 1`); `GlBackend::set_size` → `after_rasterizer_change` (`needs_full_upload`); `SoftBackend::set_size` → `needs_full_redraw`, `is_overlay_valid = false`; `App` после этого делает `request_redraw`.
- Команды приложения — `Request { grid, backend, fullscreen, redraw, exit }`, применяются `App::apply_request` после обработчика; `request.backend` переключает рендерер на лету (`switch_backend`).
- Пример `minimal` (ADR-0017) — потребитель без `assets/`: `FontFamily::system_monospace()`, `AppHandler` без событий.

## 1. Цель

Дать приложению выбор, откуда брать рамки и блоки U+2500–U+259F: процедурно (как сейчас, умолчание), из глифов шрифта или комбинированно (глиф шрифта, если он есть, иначе процедурно), с переключением на лету. Показать разницу примером `pseudographica` с тремя таблицами.

## 2. Границы

**Входит:**

1. **Режим в библиотеке.** `rasterizer::BoxDrawingMode { Procedural, Font, Combined }` (`Default` — `Procedural`); у `Rasterizer` поле режима, `set_box_drawing_mode(mode)`, `box_drawing_mode()`. `rasterize`: `Procedural` — как сейчас; `Font` — псевдографика идёт путём шрифта (нет глифа — пустая ячейка, как для любого символа); `Combined` — сначала шрифт, при отсутствии глифа — процедурно. SVG главнее в любом режиме. `is_style_independent` для псевдографики — `true` только в `Procedural` (в остальных режимах у Bold/Italic свои глифы).
2. **Переключение на лету.** `Atlas::set_box_drawing_mode(mode)` — режим растеризатора и сброс страницы (как `set_size`); `GlBackend`/`SoftBackend::set_box_drawing_mode` — то же, что после `set_size` (полная перезаливка / полная перерисовка); `Request::box_drawing: Option<BoxDrawingMode>`, применяется `App::apply_request` к текущему бэкенду с последующим `request_redraw`. Режим переживает смену бэкенда и DPI (живёт в `Rasterizer`, который переезжает между бэкендами).
3. **Пример** `crates/gterm/examples/pseudographica.rs` (без `assets/`, шрифт — `FontFamily::system_monospace()`, `AppOptions::font_size_px = 11`, `FixedGrid`): три таблицы в ряд — одиночные линии (`─│┌┐└┘├┤┬┴┼`), двойные (`═║╔╗╚╝╠╣╦╩╬`), смесь (жирные `━┃┏┓┗┛`, стыки одиночных с двойными `╒╕╘╛╞╡╤╧╪`, штриховые `┄┅┆┇`, дуги `╭╮╯╰`, тени и блоки `░▒▓█▀▄`); в ячейках таблиц — текст. Верхняя строка — текущий рендерер и режим псевдографики; нижняя строка — подсказка по клавишам. Клавиши: `1`/`2`/`3` — OpenGL 3.3 / GLES 3.0 / Software (`Request::backend`, как в демо FR-28), `q`/`w`/`e` — `Procedural`/`Font`/`Combined` (`Request::box_drawing`), `Esc` — выход (как у всех бинарников проекта). Явная секция `[[example]]` в манифесте библиотеки.
4. Тесты (§4), ADR-0018, ТЗ 1.15 (FR-8.4, FR-25 `Request`, §5.1, §13), `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`, отчёты `docs/done|test|verify/`.

**Не входит:**

- режим псевдографики в демо-бинарниках и в `minimal` (они остаются на `Procedural`), флаги CLI для него;
- изменение самих процедурных формул (толщины, тени) и SVG-пути;
- синтез рамок для шрифтов без глифов в режиме `Font` (пустая ячейка — ожидаемое поведение);
- сохранение режима между запусками.

## 3. Контракты

- Умолчание — `Procedural`: golden, `stage4_gl` и все эталоны не меняются ни байтом; у приложений, не трогающих режим, поведение прежнее.
- В любом режиме GL и Software бит-идентичны: оба читают готовое покрытие из атласа; смена режима — промах атласа, горячий путь кадра не меняется (NFR-6), `unsafe` не добавляется (NFR-9).
- `Combined` на кодовой точке, которой нет в шрифте, даёт растр, равный `Procedural`; `Font` на ней даёт пустую ячейку (`rasterize` → `false`).
- Смена режима через `Request` на любом бэкенде: следующий кадр уже в новом режиме, прежние слоты атласа не переиспользуются (`resets` растёт), наложение Software пересобирается.
- Пример зависит только от `gterm` (+ `winit` для типов клавиш, как любой `AppHandler`), без ресурсов рядом с exe; на системном шрифте без глифов рамок режим `Font` показывает пустые ячейки — это демонстрация, а не ошибка.

## 5. Риски (принятые осознанно)

- В режиме `Font` стыки линий между ячейками зависят от хинтинга и метрик шрифта: возможны зазоры и серые тонкие линии — именно поэтому умолчание остаётся процедурным (ADR-0002).
- В `Font`/`Combined` псевдографика занимает каналы атласа по начертаниям: больше промахов при смешении `BOLD`/`ITALIC`, ёмкость страницы не меняется.
- Системный шрифт по умолчанию может не иметь блоков и теней U+2580–U+259F: в `Font` третья таблица примера частично пуста (демонстрация режима).

## 6. Открытые решения

Решения из переписки 2026-10-23 приняты как постановка: три режима, переключение клавишами, пример отдельно от `minimal`. Остаётся подтвердить:

- **О1.** Переключение на лету — отдельным путём `set_box_drawing_mode` на атласе и бэкендах (рекомендуется: симметрично `set_size`, без пересоздания GL-контекста), либо пересозданием рендерера текущего уровня (меньше кода, но `on_backend_changed` придёт повторно и GL-контекст создаётся заново).
- **О2.** Шрифт примера — системный (`system_monospace()`, как у `minimal`; на машине владельца это `Cascadia Mono` с глифами рамок), либо `assets/` репозитория (тогда пример зависит от каталога демо — против ADR-0017).
