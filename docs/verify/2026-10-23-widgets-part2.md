# Проверка критериев приёмки: виджеты `gterm-widgets`, часть 2 (ADR-0032)

ТЗ — `docs/spec/2026-10-23-widgets.md`, §4, в части виджетов второй задачи (`Tabs`, `Gauge`, `LineGauge`, `Scrollbar`, `Clear`). Второй проход (BP-09): каждый критерий сверен с кодом, тестом или сохранённым выводом команды.

| № | Критерий | Статус | Подтверждение |
|---|---|---|---|
| К1 | `gterm` не изменён; `cargo test` в корне гоняет все пакеты | ✅ | `git status` — изменённых файлов в `crates/gterm` нет; полный прогон 298 тестов |
| К2 | Каждый виджет рендерится в ожидаемый текст и стили, не выходит за `area` | ✅ | `tests/widgets_part2.rs` (`Clear`, `Gauge`, `LineGauge`), `tests/tabs.rs`, `tests/scrollbar.rs`; обрезка — `clear_resets_only_its_area…`, `gauge_draws_inside_its_block_and_never_outside_the_area`, `divider_padding_clipping…`, `a_vertical_bar_touches_only_the_last_column…` |
| К3 | Раскладка | — | часть 1, не затрагивалась |
| К4 | `Popup` | — | часть 1, не затрагивалась |
| К5 | Пример: экран из §2 п.6 на трёх бэкендах; глазами | 🔶 | код `examples/widgets.rs`; запуск `--backend=soft --fail-frames=2` — кадр, повтор, код 1; GL/GLES и вид — глазами за владельцем. Отличие от п.6: `Gauge` — на второй вкладке, внизу экрана — `LineGauge` |
| К6 | Гейты, размер примера, документы | ✅ | fmt, clippy `--all-targets -D warnings`, 298 тестов; `widgets.exe` 1 249 792 Б; ADR-0032 + индекс, ТЗ проекта 1.27, `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`, отчёты |

**Контракты §3 ТЗ.** «Виджет рисует только внутри `area`» — тесты обрезки выше. «Крейт не содержит `unsafe`» — в новых файлах `unsafe` нет (`grep` по `clear.rs`, `gauge.rs`, `tabs.rs`, `scrollbar.rs`). «Зависит только от `gterm`» — уже не так с ADR-0026/0030 (`winit`, необязательный `arboard`); часть 2 новых зависимостей не добавила.

**Отклонения от ТЗ (решение владельца 2026-11-12, ADR-0032).** `Tabs` — контрол с вводом, хотя ТЗ исключает обработку ввода в виджетах; `Scrollbar` — `Widget` без `StatefulWidget` (состояние несёт в себе); вертикальная и горизонтальная ориентации без вариантов «слева/сверху»; восьмушки `Gauge` включены по умолчанию.

**След прохода.** Открыто заново 5 мест: вывод полного `cargo test` (43 бинарника), вывод запуска примера, сводка размеров release, результаты десяти мутаций с `cmp` восстановленных файлов, `git status`.

Отброшенных находок нет.
