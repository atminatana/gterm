# ADR-0029. Карта «сочетание → сообщение» в описании экрана: срабатывание на нажатие после контрола под фокусом, карта у модального слоя, трекер в состоянии приложения; `AppHandler::on_focus`

- **Дата:** 2026-11-12
- **Статус:** Accepted (ТЗ `docs/spec/2026-11-12-hotkey-map.md` утверждено владельцем 2026-11-12; О1–О3 — рекомендованные варианты).
- **Тема:** ТЗ §13, FR-25; ADR-0004, ADR-0026, ADR-0027, ADR-0028. План — `docs/plans/2026-11-12-hotkey-map.md`.

## Контекст

ADR-0028 дал раскладко-независимую структуру комбинации и трекер, но `gterm-widgets` ими не пользуется: глобальные клавиши приложение разбирает само из «не принятого деревом» по `logical_key` (в примере `widgets` — `"p" | "з"`), при модальном слое они до приложения не доходят. Нужны привязки в описании экрана, публикующие сообщения тем же путём, что `on_activate`. Потерю фокуса окна библиотека не сообщала — клавиша, отпущенная вне окна, «зависала» в трекере.

## Решение

1. **Карта `HotkeyMap<M>`** (`gterm-widgets`, `src/hotkeys.rs`) — упорядоченный список «образец `Hotkey` → сообщение»; строится один раз, хранится в состоянии приложения, `M: Clone`. Подключение: `Ui::hotkeys(&mut tracker, &map)` на корне, `Modal::hotkeys(&map)` у слоя. Трекер `HotkeyTracker` один, в состоянии приложения.
2. **Срабатывание на нажатие, после контрола под фокусом.** `Ui::key` всегда кормит трекер (нажатия, отпускания, автоповтор; и при модальном слое), затем нажатие идёт прежним путём (слой либо `Tab` → контрол → текст). Только не принятое нажатие, учтённое трекером, сопоставляется с картой: поле ввода поглощает набор и свои комбинации, до карты доходит остальное. Автоповтор привязку не вызывает.
3. **Сопоставление в два шага:** полная история `full()` (аккорды: `Ctrl+[K,U]` в момент нажатия `U`), затем цепочка удержанных `current()` (простые сочетания: `Ctrl+V` после `Ctrl+C` без отпускания `Ctrl`); первая привязка в порядке объявления, срабатывает одна.
4. **Модальный слой забирает всё:** при слое карта экрана не действует, действует только карта слоя; `on_escape` слоя раньше его карты.
5. **Запись — имена физических клавиш (латиница), акселераторов `Alt+буква` нет.**
6. **`AppHandler::on_focus(focused, ctx)`** в `gterm` из `WindowEvent::Focused`; библиотека трекер не сбрасывает (ADR-0004) — приложение вызывает `reset()` при потере фокуса.

## Альтернативы и обоснование

| Вариант | Почему отклонён |
|---|---|
| Срабатывание на отпускание / на `complete` | владелец: на нажатие — как привычные сочетания; аккорд на нажатие распознаётся по `full()` |
| Карта раньше контрола под фокусом | привязка без модификаторов съела бы набор в поле ввода; поле должно само поглощать `Ctrl+V`/`Ctrl+X` |
| Сопоставление только с `full()` | `Ctrl+C`, затем `Ctrl+V` без отпускания `Ctrl` даёт `Ctrl+[C,V]` — простое сочетание не сработало бы |
| При двух совпадениях срабатывают обе привязки (О3-b) | аккорд — более точное совпадение; двойное сообщение на одно нажатие неожиданно |
| Привязки по одной в описании, `Ui::hotkey(&Hotkey, M)` (О1-b) | разобранные образцы пришлось бы хранить отдельными полями; карту удобно читать из настроек |
| Автоповтор вызывает привязку (О2-b) | опасно для разрушающих действий; трекер автоповтор и так не учитывает |
| Карта экрана действует и под модальным слоем | владелец: слой забирает всё |
| Акселераторы `Alt+буква` по букве подписи | зависят от раскладки; владелец: всегда латиница, без акселерации |
| Библиотека сама сбрасывает трекер при потере фокуса | трекер принадлежит приложению, библиотека ввод не интерпретирует (ADR-0004) |

## Последствия

**Плюсы:** раскладко-независимые привязки в описании экрана и у слоя, сообщения тем же путём, что у контролов; аккорды и простые сочетания в одной карте; приложение узнаёт о потере фокуса окна.

**Минусы / риски:** `M: Clone` у подключающих карту; привязка-префикс не подавляется (`Ctrl+K` и `Ctrl+[K,U]` сработают обе по очереди); привязка без модификаторов срабатывает при фокусе на контроле, не принимающем букву; без `reset()` при потере фокуса клавиша «зависает»; доставка настоящего `KeyEvent` и `on_focus` автотестом не покрыты (ввод и фокус оконные тесты не инжектируют). Размеры release — в `docs/done/2026-11-12-hotkey-map.md`.
