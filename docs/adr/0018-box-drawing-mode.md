# ADR-0018. Режим псевдографики: процедурная, из шрифта или комбинированная, переключение на лету

- **Дата:** 2026-10-23
- **Статус:** Accepted (решения владельца 2026-10-23: три режима, переключение через `Request`, отдельный путь на атласе и бэкендах — О1, пример на системном шрифте 11 px — О2). Дополняет ADR-0002: процедурные формулы остаются умолчанием.
- **Тема:** ТЗ FR-8.4, FR-9, FR-13, FR-25, FR-28, §13. ТЗ задачи — `docs/spec/2026-10-23-box-drawing-mode.md`, план — `docs/plans/2026-10-23-box-drawing-mode.md`.

## Контекст

С ADR-0002 рамки и блоки U+2500–U+259F рисуются по формулам на сетке ячейки и безусловно перекрывают глифы шрифта: линии ложатся на пиксели и стыкуются между ячейками без зазоров. После ADR-0017 библиотека работает на произвольном системном шрифте, и владельцу нужна возможность показывать рамки так, как их нарисовал автор шрифта, — с переключением на лету для сравнения. Путь смены растеризации на месте уже есть для DPI: сброс страницы атласа, полная перезаливка (GL) или перерисовка (Software).

## Решение

1. **Три режима** — `rasterizer::BoxDrawingMode`: `Procedural` (умолчание, прежнее поведение), `Font` (глиф шрифта; нет глифа — пустая ячейка, как у любого символа), `Combined` (глиф шрифта, если он есть, иначе формула). SVG-глифы главнее в любом режиме. Режим — состояние `Rasterizer`: переживает смену DPI и бэкенда вместе с ним.
2. **Каналы атласа.** Псевдографика одинакова во всех начертаниях только в `Procedural`; в `Font` и `Combined` у `BOLD`/`ITALIC` свои глифы — атлас заполняет каналы по начертаниям, как для букв.
3. **Переключение на лету** — тем же путём, что смена размера: `Atlas::set_box_drawing_mode` (режим + сброс страницы), `GlBackend`/`SoftBackend::set_box_drawing_mode` (полная перезаливка / полная перерисовка, наложение Software пересобирается), `Request::box_drawing` → `App::apply_request` → текущий бэкенд и перерисовка. GL-контекст не пересоздаётся, `on_backend_changed` не приходит.
4. **Демонстрация** — пример `crates/gterm/examples/pseudographica.rs` без `assets/`: системный моноширинный шрифт 11 px, три таблицы (одиночные, двойные, смесь), клавиши `1/2/3` — бэкенд, `q/w/e` — режим, статус сверху, подсказка снизу.

## Альтернативы и обоснование

| Вариант | Почему отклонён |
|---|---|
| Cargo-фича вместо режима во время выполнения | потребитель пересобирает крейт; один бинарник не может показать оба варианта |
| Только два режима (процедурный / шрифт) | системные шрифты часто без блоков и теней U+2580–U+259F — `Combined` закрывает пустые ячейки формулой |
| Переключение пересозданием рендерера текущего уровня | меньше кода, но GL-контекст создаётся заново и `on_backend_changed` приходит повторно без смены бэкенда |
| Режим в `AppOptions` без переключения на лету | не даёт сравнить режимы в одном окне — а это цель примера |
| Шрифт примера из `assets/` демо | пример библиотеки зависел бы от каталога другого пакета — против ADR-0017 |

## Последствия

**Плюсы:** умолчание не меняется — golden и бит-идентичность GL ↔ Software нетронуты; приложение выбирает источник рамок и меняет его на лету; горячий путь кадра тот же (смена режима — промах атласа), `unsafe` не добавляется.

**Минусы / риски:** в `Font` стыки линий зависят от хинтинга и метрик шрифта (зазоры, серые тонкие линии — причина ADR-0002); в `Font`/`Combined` псевдографика занимает каналы по начертаниям — больше промахов атласа при смешении стилей; смена режима сбрасывает всю страницу атласа (первый кадр растеризует видимые глифы заново); размер release 2026-10-23: `demo.exe` 1 522 688 Б (без изменений: демо режим не использует, код вырезан LTO), `pseudographica.exe` 1 147 392 Б, `minimal.exe` 1 144 832 Б (`docs/done/2026-10-23-box-drawing-mode.md`).
