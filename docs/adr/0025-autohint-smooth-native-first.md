# ADR-0025. Цель хинтинга по движку: автохинтер в `Smooth/Normal`; файл с родными инструкциями предпочтительнее

- **Дата:** 2026-10-27
- **Статус:** Accepted (постановка владельца 2026-10-27: «Делай оба» — после разбора скриншота примера виджетов против Блокнота). Уточняет ADR-0002 п.2 и ADR-0017 п.3–4.
- **Тема:** ТЗ FR-8.1, FR-8.4. ТЗ задачи — `docs/spec/2026-10-27-autohint-smooth.md`, план — `docs/plans/2026-10-27-autohint-smooth.md`.

## Контекст

ADR-0002 выбрал `Target::Mono` на PT Mono с родными TrueType-инструкциями: интерпретатор даёт штрихи 1 px. Позже появились автохинтер (`hinting_engine`: глифы без инструкций → `Engine::Auto`) и системные шрифты (ADR-0017), а цель осталась `Mono` для обоих движков. Разбор 2026-10-27 показал два дефекта, сложившихся в один: (1) `from_system_database` сортирует пути, а `from_faces` берёт первый Regular — на машине с `Cascadia Mono` в двух сборках побеждает `CascadiaMono-Regular.otf` (CFF, инструкций нет), а не `.ttf` с 3 581 байтом инструкций; (2) автохинтер skrifa в `Mono` (аналог `FT_LOAD_TARGET_MONO`, по документации крейта «только для алиасной монохромной растеризации») ставит флаги `HORIZONTAL_SNAP | VERTICAL_SNAP | STEM_ADJUST | MONO`: стойки привязываются к сетке по обеим осям и расширяются до 2 px, x-высота и высота заглавных округляются вверх, буквы сжимаются — при 8-битном покрытии это выглядит как грубый битмап. То же у шрифта репозитория RobotoMono (инструкций нет): при 16 px `С` занимает 8 колонок из 10, стойка `к` — 2 px. У инструктированного `.ttf` `Mono` и `Smooth` дают бит в бит одинаковый растр — цель вредит только автохинтеру.

## Решение

1. **Цель хинтинга зависит от движка** (`rasterizer::hinting_target`): интерпретатор — `Target::Mono` (ADR-0002 без изменений), автохинтер — `Target::Smooth { mode: Normal }` (умолчание FreeType `FT_LOAD_TARGET_NORMAL`: только `STEM_ADJUST` — ширина стойки приводится к целым пикселям, положение и пропорции не трогаются).
2. **Среди файлов одного начертания предпочитается тот, чьи глифы несут родные инструкции** (`font::has_glyph_instructions`: `maxp.maxSizeOfInstructions > 0`); среди равных — прежний порядок (сортировка путей каталога/системы, порядок списка `from_files`). Признак — одна функция, ею же `hinting_engine` выбирает движок: «файл, который хинтует интерпретатор» и «файл, который берём» — одно определение.
3. Golden-эталоны `soft_golden_{16,32}px.bin` перезаписаны: шрифт репозитория идёт через автохинтер, его растр изменился осознанно (16 px — 7,5 % пикселей, 32 px — 3,4 %).

## Альтернативы и обоснование

| Вариант | Почему отклонён |
|---|---|
| Оставить `Mono` всюду | автохинтер в этом режиме рассчитан на 1-битный растр: 2-пиксельные стойки, сжатые буквы (скриншот владельца) |
| `Smooth/Light` для автохинтера | горизонтальный хинтинг выключен полностью: при 16 px стойка `к` ложится на полпикселя — две серые колонки вместо одной чёткой |
| Предпочитать `.ttf` перед `.otf` по расширению | расширение не говорит об инструкциях: бывают неинструктированные `.ttf` и `glyf` внутри `.otf`; признак из `maxp` — тот же, что у выбора движка |
| Предпочитать `glyf` перед CFF по формату контуров | `glyf` без инструкций хинтуется тем же автохинтером, что и CFF — выигрыша нет |
| Только одно из двух исправлений | первое чинит лишь семейства с двумя сборками, второе не трогает выбор файла; вместе закрывают и системные шрифты, и шрифт репозитория |

## Последствия

**Плюсы:** текст на шрифтах без инструкций (CFF, Nerd-сборки, шрифт репозитория) сохраняет пропорции, стойки 1 px; семейство с двумя сборками берёт инструктированную и хинтуется интерпретатором (пример виджетов на `Cascadia Mono`: `.ttf` вместо `.otf`); путь интерпретатора байт в байт прежний; GL ↔ Software identical; `unsafe` и горячий путь не затронуты.

**Минусы / риски:** все golden перезаписаны — прежние эталоны не воспроизводимы; в `Smooth/Normal` часть стоек стоит на дробных позициях (серые края с двух сторон) — цена сохранения пропорций; семейство, где инструктировано не Regular начертание, получает разные движки по начертаниям, как и раньше; размер release 2026-10-27: `demo.exe` 1 543 168 Б (+512), `widgets.exe` 1 189 888 Б (+3 072) (`docs/done/2026-10-27-autohint-smooth.md`).
