# ADR — архитектурные решения

Каталог фиксирует принятые архитектурные решения проекта `gterm`: выбор среди нескольких разумных вариантов, отклонения от ТЗ, значимые трейд-оффы, сквозные решения. Мелкие локальные решения (имена, порядок полей) здесь не фиксируются.

## Соглашения

- Имя файла: `NNNN-kebab-title.md`, `NNNN` — следующий порядковый номер.
- Разделы: *Дата / Статус / Тема* → **Контекст** → **Решение** → **Альтернативы и обоснование** → **Последствия** (плюсы / минусы-риски).
- Статусы: `Accepted`, `Superseded by NNNN`, `Deprecated`. ADR создаётся только для **принятого** решения; открытые вопросы живут в плане/ТЗ, не здесь.
- Решение принимает владелец проекта; агент только записывает.
