# Отчёт о тестах: выравнивание вписанных рамок по пиксельной сетке (вариант Г)

- **Задача:** `2026-10-23-box-glyph-snap` (ADR-0021)
- **Окружение:** Windows 10 Pro 19045, NVIDIA GTX 1060 3GB (драйвер 581.57), Rust stable 1.98.1; тесты — debug, размеры — release; системный шрифт — `Cascadia Mono`

## Состав

| Файл | Тесты |
|---|---|
| `crates/gterm/tests/box_drawing_mode.rs::fitted_box_glyphs_are_pixel_aligned` (1, **К2**) | режим `Font`, шрифт репозитория 16 px: у `─ │ ┼ ═ ║ ╬ ┏ ┃ ╪` все пиксели 0 или 255; самый плотный штрих (максимум краски по колонкам или строкам) ≥ 255 |
| `font_box_glyphs_reach_cell_edges` (**К3**) | краска по длине равномерна: `─` 255 на колонку, `│` 510 на строку, края `┼` равны краям линий |
| `stage4_gl` (**К4**) | сцены `box font 16px`, `box combined 16px` identical на GL 3.3 и GLES 3.0 |
| прежние (177) | без изменений эталонов |

## Результат прогона

- `cargo test`: **178 тестов** harness, 0 падений; оконные бинарники ok; golden без изменений.
- Дамп до утверждения теста: `─` — одна строка, `│` — 2 колонки, `═` — два штриха по 2 px с зазором 1 px, `╬`/`╤` — зазоры чистые, `┏` — 3 px, `╭` — сглаженная дуга, `░` — точечный узор шрифта.
- Мутация (исходник восстановлен): без выравнивания К2 падает на полутонах.
- Гейты: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` — чисто.
