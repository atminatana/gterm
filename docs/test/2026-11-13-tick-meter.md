# Отчёт о тестах: периодический тик приложения (ADR-0033) и индикатор уровня `Meter` (ADR-0034)

- **Задача:** `2026-11-13-tick-meter`
- **Окружение:** Windows 10 Pro 19045, Rust stable; тесты — debug, размеры — release; бэкенд оконных тестов — OpenGL 3.3.

## Состав

### `crates/gterm/tests/tick_events.rs` — оконный бинарник, `harness = false`, 4 сценария дочерними процессами

| Сценарий | Что проверяет |
|---|---|
| `period` | период 20 мс из `AppOptions`: 16 тиков до выхода, каждый не раньше чем через период после предыдущего; тики без `ctx.redraw()` не меняют `stats.frames`; пять тиков с `ctx.redraw()` дают не меньше трёх кадров (К1, К4) |
| `no-period` | без периода за 150 мс работы окна (цикл ведут кадры из `on_frame`) `on_tick` не приходит ни разу (К2) |
| `switch` | период включается из `on_backend_changed` через `Request` (10 мс), после четвёртого тика меняется на 40 мс — интервалы не короче нового периода, после седьмого выключается — за 200 мс новых тиков нет (К3) |
| `lag` | период 10 мс, обработчик третьего тика спит 100 мс: следующий тик приходит не раньше чем через период после возврата из обработчика, пачки нет (К5) |

Общий запуск окна — `tests/events_common/launch.rs` (`run_handler`: шрифт репозитория, сторож 60 с); им же теперь пользуется `events_common::run_to_end`.

### `crates/gterm-widgets/tests/meter.rs` — 6 тестов без окна

| Тест | Что проверяет |
|---|---|
| `meter_fills_by_ratio_in_half_cell_steps_and_clamps_the_ratio` | снимки строки: целые и половинные ячейки, округление до ближайшей половины, 0 и 1, значения вне отрезка, `NaN`, индикатор без уровня |
| `meter_cells_take_the_colour_of_their_zone_by_position` | цвет каждой ячейки по её зоне при полном и частичном уровне; стиль незаполненной части; половинная ячейка — цвет зоны и фон пустой части |
| `meter_without_zones_uses_the_filled_style_and_zones_patch_it` | без зон — `filled_style`; зона накладывается поверх него, до первого порога — без зоны |
| `meter_marks_the_peak_in_its_zone_colour_inside_and_beyond_the_fill` | пик правее заполнения, внутри него и на половинной ячейке, цвет зоны; границы: 1, больше 1, близко к нулю, 0, `NaN`, `None`; знак пика по умолчанию |
| `meter_symbols_are_configurable` | свои символы заполненной, половинной и пустой ячейки |
| `meter_draws_inside_its_block_and_never_outside_the_area` | внутри `Block`; на всю высоту области; стиль области только внутри неё; область шире буфера, пустая и вне буфера |

## Ограничения

- Оконный тест проверяет интервалы только снизу; верхняя граница зависит от машины и системного таймера.
- Задержка обработчика в сценарии `lag` — `thread::sleep` внутри `on_tick`: это предмет проверки, а не синхронизация теста.
- Linux (X11, Wayland) не проверялся.
- Вид `Meter` на Software и GLES глазами не проверялся: виджеты пишут только в `ScreenBuffer`, равенство бэкендов держит `tests/stage4_gl.rs`.
- Время полного прогона runner не суммирует — не измерено.
