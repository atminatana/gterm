# Тесты: SVG-глифы

## Состав

`tests/svg_glyphs.rs` — 15 тестов на фикстурах `tests/data/svg/` (отдельно от `assets/`, golden шрифта от них не зависит):

| Фикстура | Назначение |
|---|---|
| `0E000.svg` | квадрат на весь холст 10×10; 5-значное имя той же точки, что `E000.svg`, сортируется первым — побеждает |
| `E000.svg` | пустой холст — проигравший повтор |
| `e001.svg` | имя в нижнем регистре; кольцо `fill="none"` + `stroke-width="2"` |
| `F0041.svg` | `<g transform="translate(5 0)">` — правая половина; перекрывает иконку MDI шрифта |
| `10FFFD.svg` | `fill-rule="evenodd"` — рамка с дырой |
| `2500.svg` | круг; перекрывает процедурную линию `─` |
| `E002.svg` | обрезанный XML — ошибка разбора, пропуск |
| `tree.svg` | неверное имя, пропуск |

| Модуль | Тесты |
|---|---|
| `file_names` | допустимые имена (4–6 цифр, регистр, `10FFFF`), 12 недопустимых (`U+`, `uni`, суффикс, 3 и 7 цифр, `110000`, суррогат `D800`, не `.svg`, без расширения, пустое, не-ASCII) |
| `loading` | набор после пропусков ровно `[2500, E000, E001, F0041, 10FFFD]`; нет каталога → пусто; при повторе побеждает первое имя |
| `rasterization` | вписывание 10×10 в 10×20: строки 0–4 и 15–19 — 0, 5–14 — 255; кольцо; `transform`; `evenodd`; детерминизм (13×29); без SVG буфер не тронут |
| `priority` | SVG перекрывает иконку шрифта и псевдографику (равен отдельному `SvgGlyphs`, не равен процедурной линии); глифы без SVG (`A`, `g`, `Ж`, `═`, U+F0001, Bold) идентичны растеризатору без SVG |
| `atlas` | SVG-глиф готов и одинаков во всех 4 каналах; после `set_size(32)` растр совпадает с растеризацией с нуля |

`tests/stage4_gl.rs` — шестая сцена `svg 26px` (окно 500×280, 5 SVG-глифов с `BOLD`/`ITALIC`/`INVERSE`/`BOLD|ITALIC`), оба уровня GL, 2 кадра, допуск 0.

## Результат прогона

`cargo test`: 121 тест ok + 4 оконных бинарника ok. `stage4_gl`: `GL ↔ Software identical, 6 scenes` на OpenGL 3.3 и OpenGL ES 3.0. Время `svg_glyphs` — 0,07 с.

## Ограничения

- Окно `demo`/`full_table` с картой проверяется глазами на машине владельца (§11.3); здесь проверен кадр Software-рендерера (`docs/research/2026-10-08-svg-map.png`).
- Сложные SVG из редакторов (Inkscape/Figma: `<defs>`/`<use>`, вложенные группы с `clip-path`) фикстурами не покрыты; `use` и группы обрабатывает `usvg`, обрезка игнорируется по ADR-0008.
