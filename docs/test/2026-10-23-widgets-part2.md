## Результат прогона

- Базовый прогон до правок — коммит `68ea6db`: 283 теста, 0 падений.
- Первый прогон `widgets_part2`: 4 из 5; падение `gauge_draws_inside_its_block…` — ошибка теста (снимок из одной строки для экрана в две строки, `tests/common/mod.rs:36`), исправлено ожидание.
- Первая сборка `tests/scrollbar.rs`: `E0034` — неоднозначный `render` у типа с двумя трейтами; исправлен код (`Scrollbar` — только `Widget`).
- `cargo test -p gterm-widgets`: 103 теста, 0 падений. `cargo test` в корне: **298 тестов**, 0 падений, 43 бинарника, код возврата 0.
- Мутации (исходники восстановлены побайтно): `gauge.rs` — 4 из 4 пойманы; `tabs.rs` — 3 пойманы, 1 эквивалентная (ограничение `→` у края дублируется проверкой индекса); `scrollbar.rs` — 3 из 3 пойманы.
- Гейты: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` — чисто.

## Ограничения

- Вид примера на окне (вкладки, вторая страница, полоса у списка) — только глазами.
- Связка «полоса прокрутки ↔ состояние списка» собрана в примере и автотестом не покрыта: тесты полосы задают состояние напрямую.
- Время полного прогона runner не суммирует — не измерено.
