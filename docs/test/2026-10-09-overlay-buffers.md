## Результат прогона

- `cargo test`: 151 тест harness, 0 падений; оконные `stage6_events`, `stage6_events_auto`, `stage6_fallback` и 5 сценариев `stage8_faults` — `ok`.
- `stage4_gl`: «OpenGL 3.3: identical, 8 scenes», «OpenGL ES 3.0: identical, 8 scenes».
- Мутации:
  - без наложения в основном шейдере — `overlay 16px pass 0: pixel 1755 (5, 7): gl 0x000080 vs soft 0x0830B0`;
  - без фона записи в `overlay.frag` — то же расхождение.

  После восстановления — identical.
- Golden-эталоны не менялись (`git status tests/golden` пуст).

## Ограничения

- Пример `overlay` проверен только запуском на 6 с на трёх бэкендах (stderr без ошибок). Как он выглядит — за владельцем (§11.3).
- Только NVIDIA. Другие драйверы и неполный FBO `RGBA8UI` не проверялись.
- Приложение с наложением на весь экран в Software ниже NFR-5 — ⚠ отчёта о выполнении.
