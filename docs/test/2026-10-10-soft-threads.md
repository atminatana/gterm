# Отчёт о тестах: многопоточная отрисовка Software-рендерера

- **Задача:** `2026-10-10-soft-threads` (ADR-0016)
- **Окружение:** Windows 10 Pro 19045, 12 логических ядер, NVIDIA GTX 1060 3GB (драйвер 581.57), Rust stable 1.98.1; тесты — debug, замеры — release (`opt-level = "z"`)

## Состав

| Файл | Тесты |
|---|---|
| `tests/soft_threads.rs` (4) | 1 ↔ 4 потока, 6 кадров (полный, частичные с меняющимися строками, наложение из двух слоёв движется и выходит за сетку, кадр без наложения): полосы `damage()` и пиксели равны — окно равно сетке, больше сетки (центрирование), меньше сетки (обрезка справа и снизу); `new` даёт 1…4 потока |
| `tests/soft_threads_alloc.rs` (1) | свой `#[global_allocator]`-счётчик, один тест в бинарнике: 3 кадра разогрева, затем 20 кадров с полной перезаписью экрана и наложением, меняющимся каждый кадр — 0 выделений на 1 и на 4 потоках |

Бит-идентичность держат и существующие: golden `stage3_render`, `stage4_gl` (8 сцен, оба уровня), `tests/overlay.rs` (26), `soft_partial_redraw`, `stage6_app` — все через `SoftBackend::new`, то есть на пуле.

## Результат прогона

- `cargo test`: 167 тестов harness, 0 падений; `stage6_events`, `stage6_events_auto`, `stage6_fallback`, `stage8_faults` — ok.
- `stage4_gl`: «OpenGL 3.3: GL ↔ Software identical, 8 scenes», «OpenGL ES 3.0: GL ↔ Software identical, 8 scenes».
- Мутации — обе пойманы (см. `docs/done/…`).

## Замеры (release, 120×40, VSync выключен)

`--bench --backend=soft` (30 + 300 кадров, полная перезапись сетки). Число потоков в копии крейта задавалось переменной окружения; «до задачи» — сборка `HEAD` (`git archive`). Два прогона:

| Сборка | без наложения: `cpu`, мс / FPS | с наложением: `cpu`, мс / FPS |
|---|---|---|
| до задачи | 7,83–7,93 / 111,0–112,5 | 13,03–13,33 / 68,8–71,1 |
| 1 поток | 6,63–6,72 / 131,0–132,8 | 10,12–10,17 / 88,2–89,1 |
| 2 потока | 3,47–3,48 / 226,3–228,1 | 5,19 / 158,2–158,9 |
| 4 потока | 1,86–1,90 / 330,7–339,8 | 2,88–2,90 / 243,7–247,3 |
| репозиторий, `SoftBackend::new` (4 потока) | — / 335,7 | — / 253,0 |

Кадр с одной изменённой строкой (5 000 кадров, бинарник-замер в копии): до задачи 159,8–164,5 мкс; 1 поток 137,3–138,8; 4 потока 138,1–142,5 (меньше 8 строк — текущий поток).

## Ограничения

- Простой CPU с пулом не замерялся.
- Наложение, меняющееся каждый кадр, отдельным `--bench` не замерялось.
- Машины с 1–2 vCPU (ВМ, RDP) не проверялись.
