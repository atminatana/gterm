# Отчёт о тестах: набор виджетов `gterm-widgets`, часть 1

- **Задача:** `2026-10-23-widgets` (ADR-0023)
- **Окружение:** Windows 10 Pro 19045, NVIDIA GTX 1060 3GB (драйвер 581.57), Rust stable 1.98.1; тесты — debug, размеры — release; системный шрифт примера — `Cascadia Mono`

## Состав (`crates/gterm-widgets/tests/`)

| Файл | Тесты |
|---|---|
| `layout.rs` (4) | `length_and_fill` (веса 1:3, остаток первым), `percentage_min_max` (проценты, `Min` растёт без `Fill` и не растёт с ним, `Max` до предела раньше `Fill`, `Max` поровну), `shortage_cuts_from_the_end_and_never_overflows` (урезание с конца, проценты сверх 100, сумма ≤ ширины для всех ширин 0…12), `spacing_margin_and_positions` (поля, зазоры, позиции, пустая раскладка) |
| `text.rs` (4) | ширины по символам, стиль фрагмента поверх строки и основы, `patch`/`apply`, перенос по словам (trim/без, длинные слова по символам, пустая строка, ширина 0, ведущие пробелы) |
| `widgets.rs` (6) | `Block`: четыре вида рамок, заголовки слева/по центру/справа и снизу, `inner` с `Padding` и частичной рамкой, стиль только внутри `area`, обрезка по экрану; `Paragraph`: перенос, выравнивание, прокрутка строк и символов, стиль области и текста в блоке; `List`: символ и стиль выделения, автосмещение вперёд и назад, зажим выделения, многострочные пункты в блоке; `Table`: ширины колонок, заголовок, выделение строки со стилем, прокрутка к выделенной строке |
| `popup.rs` (2) | буфер окна: размеры, `'\0'`, фон с альфой `0xC0`, подложка `TRANSPARENT`; смешение в `SoftBackend` на шрифте репозитория: пиксель под окном между фоном экрана и цветом окна по каждому каналу, вне окна — прежний |

## Результат прогона

- `cargo test -p gterm-widgets`: 16 тестов, 0 падений; `cargo test` в корне: **199 тестов**, 0 падений, оконные бинарники ok; golden `gterm` без изменений.
- Мутации (исходник восстановлен, прогон после восстановления зелёный): список без подгонки смещения → 1 падение; раскладка без распределения остатка → 1 падение.

## Ограничения

- Вид экрана и окна глазами — на машине владельца.
- Снимки проверяют символы и контрольные ячейки стилей, не весь массив стилей.
- Тест смешения зависит от шрифта репозитория в `crates/gterm-demo/assets`.
