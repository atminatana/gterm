# Отчёт о тестах: комбинации клавиш (ADR-0028)

- **Задача:** `2026-10-30-hotkeys`
- **Окружение:** Windows 10 Pro 19045, Rust stable 1.98.1; тесты — debug, размеры — release; системный шрифт примера — `Cascadia Mono`.

## Состав (`crates/gterm/tests/hotkey.rs`, 7 тестов)

| Тест | Что проверяет |
|---|---|
| `examples_from_the_statement_round_trip_in_canonical_form` | `Ctrl+K`, `Ctrl+[K,U]`, `Space+[Ctrl+[K,U]]`, `K|U`, `K,U`, `Ctrl+Shift+K`, `Ctrl+[K|U]`, `Ctrl+S|Super+S`, `Ctrl+[K,K]`, `Alt+F4`, `Ctrl+BracketLeft`, `Shift+Comma,Esc`, `Ctrl` — разбор даёт канонический вид и разбирается обратно в равное значение |
| `names_are_case_insensitive_and_modifiers_are_canonically_ordered` | регистр и пробелы, `Shift+Ctrl+K` ≡ `Ctrl+Shift+K`, порядок `Ctrl, Alt, Shift, Super`, модификаторы перед группой, порядок прочих клавиш значим, псевдонимы (`digit1` → `1`, `ArrowUp`/`Up`, `Escape` → `Esc`, `NumpadAdd`) |
| `parse_errors_carry_the_position` | `Ctrl+`, `,K`, `Ctrl+[]`, `Ctrl+[K,U` (не закрыта), `K]`, `K-U`, `Ctrl+Ж`, `Ctrl+Plus`, пустая строка, `K||U` — вид и позиция ошибки, текст сообщения называет клавишу |
| `matching_handles_alternatives_at_any_level_and_ignores_modifier_order` | совпадение с собой, с альтернативой верхнего уровня и внутри группы, несовпадение при другом порядке/длине, цепочка `Shift,Ctrl,K` совпадает с `Ctrl+Shift+K`, `K|U`, пустая комбинация, `keys()` |
| `tracker_follows_the_owner_scenario_step_by_step` | Ctrl↓ K↓ K↑ U↓ Ctrl↑ U↑: `full`/`current` на каждом шаге, сигналы `Ctrl+K`, `Ctrl+U`, `Ctrl+[K,U]` (`complete`), трекер пуст после завершения, новая жизнь |
| `nested_holds_repeats_and_noise_are_recorded_as_specified` | `Space+[Ctrl+[K,U]]` с сигналами `Space+Ctrl+K`, `Space+Ctrl+U`, `Space+Ctrl`; повтор `Ctrl+Shift+[K,K]` с канонизацией; автоповтор, повторное нажатие удержанной, чужое отпускание — без изменений; `reset` |
| `keys_come_from_physical_codes_and_merge_left_and_right_modifiers` | `from_code` для левых/правых модификаторов и букв, `is_modifier`, имена `K`/`7`/`Left`/`Esc`/`Comma`, `parse_name` без учёта регистра, неизвестное имя → `None` |

## Ограничения

- `KeyEvent` без окна не сконструировать, оконные тесты ввод не инжектируют: `Key::from_event`, `HotkeyTracker::feed(&KeyEvent)`, доставка `Released` в `on_key` и фильтр в `Ui::key` проверяются чтением кода и глазами в примере; логика — через `from_code`/`feed_key`.
- Раскладко-независимость (`Ctrl+K` на русской раскладке) — только глазами.
- Время полного прогона runner не суммирует; отдельные бинарники — до 2,5 с.
