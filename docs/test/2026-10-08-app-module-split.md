# Тесты: разбиение `src/app.rs` на модули

## Состав

Новых тестов нет: перенос механический, проверяется прежним набором (характеризация поведения `App` на настоящем окне):

| Тест | Что исполняет из `src/app/` |
|---|---|
| `stage6_events`, `stage6_events_auto` (`harness = false`) | `events.rs`, `api.rs`, `window.rs` (сетка, `AutoGrid`/`FixedGrid`), `frame.rs` (тики, кадры, `on_frame`) |
| `stage6_fallback` | `chain.rs` (откат на лету), `backend.rs` |
| `stage8_faults` (5 сценариев) | `frame.rs` (повтор, инжекция), `chain.rs` (откат, конец цепочки) |
| `stage6_app` | `options.rs` (`auto_grid`, `centered_origin`), путь смены DPI на уровне рендерера |

## Результат прогона

До и после переноса одинаково: 131 тест ok, 4 оконных бинарника ok (9 строк `: ok`), `stage4_gl` — 6 сцен на OpenGL 3.3 и OpenGL ES 3.0.

## Ограничения

`App::apply_scale_factor` (событие смены DPI окна) автотестами не исполняется — проверка глазами на машине владельца с двумя мониторами разного DPI (§11.3).
