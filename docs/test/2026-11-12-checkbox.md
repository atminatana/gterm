- **Задача:** `2026-11-12-checkbox`

## Состав (`crates/gterm-widgets/tests/checkbox.rs`, 6 тестов)

| Тест | Что проверяет |
|---|---|
| `space_and_enter_toggle_and_other_keys_are_left_to_the_app` | пробел (именованная и символьная клавиша) и `Enter` переключают, одно событие `Toggled(новое)` на действие; буква и `Esc` не принимаются |
| `releasing_inside_toggles_and_releasing_outside_or_leaving_cancels` | через дерево: нажатие — захват и `pressed`, отпускание внутри — сообщение `on_toggle`; клик по подписи; отпускание вне области и уход указателя — отмена без сообщения |
| `programmatic_changes_do_not_report_events` | `with_checked`, `set_checked`, `toggle` — без события |
| `a_disabled_checkbox_takes_no_focus_and_no_input` | неактивный: не фокусируется, пробел и клик не принимает |
| `marks_label_and_styles_follow_the_state` | снимки `[ ] Опция` / `[x] Опция`, стили обычный/фокус/нажат/неактивный в порядке наложения, свои метки, обрезка подписи шириной |
| `checkboxes_in_a_group_take_part_in_the_tab_ring_and_light_its_border` | свой контрол снаружи и `Ui::group` с двумя флажками: `Tab` по кольцу, рамка группы стилем фокуса только при фокусе внутри, пробел — сообщение привязки, флажок без привязки переключается молча |
