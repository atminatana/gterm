# Отчёт о тестах: поле ввода и выпадающий список (ADR-0027)

- **Задача:** `2026-10-30-widget-edit`
- **Окружение:** Windows 10 Pro 19045, Rust stable 1.98.1; тесты — debug, размеры — release; системный шрифт примера — `Cascadia Mono`.

## Состав (`crates/gterm-widgets/tests/`)

| Файл | Тесты |
|---|---|
| `route.rs` (+2) | текст — контролу под фокусом, «не обработано» возвращается приложению, доставлен ровно одному; без кандидатов — «не обработано» |
| `modal.rs` (+2) | текст — фокусу слоя, фокус экрана не тронут; `Modal::at` (область как задана и обрезана по сетке), `on_click_outside` — только на левое нажатие мимо, один раз, движение/колесо без сообщений, внутри слоя привязка молчит, `on_close` ставит и `Esc`, без привязки — прежнее поглощение |
| `text_input.rs` (6) | текст непринятой клавиши через дерево: набор и Shift — вставка и `Changed`, Ctrl/Alt/Super — «не обработано», Esc (`"\u{1b}"`) не глотается, Enter (`"\r"`) принят как клавиша без вставки; вставка в курсор и `Changed` только при изменении, управляющие символы отброшены, `Backspace`/`Delete` на краях, `←`/`→`/`Home`/`End` с зажимом, `Enter` → `Submitted`, символьная клавиша и `Tab` — «не обработано», программные `set_value`/`clear` без событий; прокрутка держит курсор видимым (снимки «world », «hello », «llo wo»), курсор обменом fg/bg только под фокусом; клик ставит курсор с учётом прокрутки и зажима; подсказка, стиль фокуса поля и рамки, неактивное поле; привязки `on_change`/`on_submit` через дерево |
| `combo_box.rs` (5) | закрытое поле: подсказка/значение и маркер `▾`/`▴`; раскрытие `Enter`/пробелом/кликом, слой под полем (снимок рамки и пунктов), `↓`+`Enter` → `Picked` и закрытие, `Enter` на том же значении — закрытие без сообщения; `Esc` и клик мимо сворачивают без сообщений, экран под слоем клик не получает, следующий `Tab` снова экрану; клик по строке — `Picked(2)`, фокус остаётся на поле до и после выбора (кадр при открытом слое не трогает фокус экрана); поле у нижнего края — слой над ним; неактивное поле не фокусируется и не раскрывается |
| `common/mod.rs` | заглушка `Stub` получила `text`; `Msg::Text(String)` |
