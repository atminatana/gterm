# Отчёт о тестах: ускорение наложения в Software-рендерере

- **Задача:** `2026-10-10-soft-overlay-speedup` (ADR-0015)
- **Окружение:** Windows 10 Pro 19045, NVIDIA GTX 1060 3GB (драйвер 581.57), Rust stable 1.98.1; тесты — debug, `--bench` — release (`opt-level = "z"`)

## Состав

| Файл | Тесты |
|---|---|
| `tests/overlay.rs`, `overlay_type` (+2) | `clone_from` переиспользует память и даёт равную копию (ёмкость не растёт при чередовании большой и малой записи); записи различаются по ячейке, позиции и порядку |
| `tests/overlay.rs`, `software` (+6) | кадр равен кадру с нуля: та же запись при меняющемся основном экране; смена ячейки на той же позиции и возврат; запись после двух пустых кадров; смена размера окна; смена сетки; смена DPI при том же размере сетки в пикселях (сетка `big_w × big_h` → `small_w × small_h`) |
| `tests/soft_pixel_math.rs` (3) | `blend`, `over`, `composite` = прежние поканальные формулы с делением как есть: перебор всех входов канала (2²⁴ для `blend` и `over`, все `t_c ≤ t_a` для `composite`) и 2²⁰ псевдослучайных пикселей с разными каналами (LCG, воспроизводимо) |

Бит-идентичность держат и существующие тесты: golden `stage3_render`, `stage4_gl` (8 сцен, оба уровня), `soft_partial_redraw`, остальные 18 тестов `tests/overlay.rs`.

## Результат прогона

- `cargo test`: 162 теста harness, 0 падений; `stage6_events`, `stage6_events_auto`, `stage6_fallback`, `stage8_faults` — ok.
- `stage4_gl`: «OpenGL 3.3: GL ↔ Software identical, 8 scenes», «OpenGL ES 3.0: GL ↔ Software identical, 8 scenes».
- `soft_pixel_math` — 1,9–2,7 с в debug.
- Мутации (см. `docs/done/…`): все три пойманы.

## Замер `--bench --backend=soft` (release, 120×40, 30 + 300 кадров, VSync выключен)

| Сборка | без наложения, FPS | с наложением на весь экран, FPS |
|---|---|---|
| до задачи | 103,1 | 23,7 |
| после кэша текстуры | 103,3 | 48,2 |
| после пар каналов, 3 запуска | 103,6 / 114,9 / 109,5 | 65,4 / 70,7 / 70,5 |

Разбивка до задачи (копия крейта с таймерами): основной слой 8,8 мс, сборка текстуры 21,0, наложение на кадр 10,6.

## Ограничения

- Наложение в `--bench --overlay` неподвижно; меняющееся каждый кадр наложение не замерялось.
- GL не менялся, его замер не повторялся.
- Глазами (§11.3) — за владельцем.
