- **Задача:** `2026-10-23-box-glyph-fit` (ADR-0020)
- **Окружение:** Windows 10 Pro 19045, NVIDIA GTX 1060 3GB (драйвер 581.57), Rust stable 1.98.1; тесты — debug, размеры — release; системный шрифт — `Cascadia Mono`

## Состав

| Файл | Тесты |
|---|---|
| `crates/gterm/tests/box_drawing_mode.rs::font_box_glyphs_reach_cell_edges` (1, **К2**) | режим `Font`, шрифт репозитория 16 px: суммарная краска `─` по колонкам 0 / середина / край равна (378); `│` по строкам 0 / середина / край равна (329); края `┼` равны краям `─` и `│`. Допуск 2 единицы |

| прежние (175) | без изменений эталонов |

## Результат прогона

- `cargo test`: **176 тестов** harness, 0 падений; оконные бинарники ok; golden без изменений.
- `box_drawing_mode -- --nocapture`: «─ колонки (0, середина, край): [378, 378, 378]», «│ строки: [329, 329, 329]», «┼ края: колонки [378, 378, 378], строки [329, 329, 329]».
- Промежуточные замеры при разработке (хинтованный контур + вписывание): `─` [255, 255, 255], `│` [267, 267, 177] — нижняя строка на 2/3; стало основанием отказаться от хинтинга для вписываемых рамок.
- `stage4_gl`: «OpenGL 3.3: GL ↔ Software identical, 10 scenes», «OpenGL ES 3.0: … 10 scenes».
- Мутация (исходник восстановлен): вписывание отключено → К2 падает.
- Гейты: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` — чисто.

## Ограничения

- Стыки и толщина линий глазами — на машине владельца (`q` против `w`/`e`).
- Тест К2 опирается на шрифт репозитория, рисующий рамки на advance и `descent…ascent`; для шрифта с иным размахом равномерность по длине сохраняется, но края ячейки могут остаться без краски.
