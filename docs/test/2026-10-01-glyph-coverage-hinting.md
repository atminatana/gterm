# Тесты: сглаживание глифов — покрытие, хинтинг, псевдографика

## Состав

`tests/stage2_font.rs` — 24 теста:

| Модуль | Тесты | Проверяют |
|---|---|---|
| `fnt_format` (5) | round-trip покрытия (в т. ч. частичное 77 и вне глифа 0), магия/версия/усечение, таблица, поиск слота, FNV-1a | формат v2 |
| `rasterization` (5) | размер ячейки и число слотов (> 700), латиница/кириллица с чернилами, у `g` есть полные **и** частичные пиксели, процедурный слот `─` байт-в-байт равен выводу `box_drawing::draw`, весь диапазон U+2500–U+259F присутствует, детерминизм, мусор → `TtfParse` | FR-8.4 |
| `procedural_box_drawing` (6) | `─` — одна полная строка в центре (ровно `w` пикселей); `│` — один столбец, `┼` — оба; `┌` стык в центре и ничего левее/выше; `━` — 3 строки; `═` — две строки через зазор; `█`, `░`=64, `▌` левая половина, `▄` нижняя половина, `▘`; вне диапазона буфер не тронут | ADR-0002 п.4 |
| `cache` (6) | как раньше (создание, reuse с подменой, пересоздание по размеру/хешу/имени, порча, нет TTF) | FR-8.2, FR-8.5 |
| `atlas` (2) | частичное покрытие копируется в атлас (100), формула слота, `glyph()` | FR-9 |

`tests/stage3_render.rs` — 17 тестов (15 + 2 GL `#[ignore]`): алгоритм §7.3 с покрытием (`blend`, частичные пиксели), флаги, курсор, масштаб, рамка, dirty, golden.

`tests/stage1_buffer.rs` — 8 тестов (+1: цвета пустых ячеек после очистки/прокрутки/`resize`).

## Ограничения

- Golden — самосогласованный эталон, проверен визуально (PNG); форма букв «правильна» в смысле «как рисует skrifa Mono», независимого эталона нет.
- Тесты псевдографики покрывают 12 символов из 160; остальные проверены визуальным листом (`docs/verify/`).
- Время stage2 выросло с 0,3 до 0,9 с (растеризация в 4 тестах) — в пределах QG-05.
