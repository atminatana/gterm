# План: динамический атлас, начертания в каналах, Bold/Italic

- **Решение:** `docs/adr/0003-dynamic-atlas-style-channels.md`.
- **Рамки:** модуль шрифта (загрузка 4 начертаний, растеризация по требованию, атлас RGBA), `CellFlags::ITALIC`, рендерер (канал по стилю, промах кэша), демо (строки Bold/Italic/Bold Italic), ТЗ, тесты, golden. **Не входит:** GL (этап 4; но §6.3/§7.3 правятся под `RGBA8UI`), персистентный кэш, синтетические начертания.

## Открытые решения

Нет (владелец: без файла; `BOLD` = глиф + осветление; страница 2048²; подстановка начертаний по цепочке; нет Regular — ошибка).

## Шаги

| # | Шаг | Проверка |
|---|---|---|
| 1 | `cell.rs`: `CellFlags::ITALIC`; `Style` (4 варианта) из флагов | тест упаковки флагов |
| 2 | `font.rs` переписать: `FontFamily` — загрузка всех `*.ttf`/`*.otf` из `assets/`, выбор по `fsSelection`, `style_source[4]`, метрики ячейки по Regular; ошибки `NoRegularFace`, `TtfParse` | тесты: подстановка при отсутствии файла (временный каталог с подмножеством), ошибка без Regular, размер ячейки |
| 3 | `font_gen.rs` → `rasterizer.rs`: растеризация одного (глиф, стиль) в предвыделенный буфер (контур + `Mask::render_into`), движок хинтинга как сейчас, процедурная псевдографика | тест детерминизма, тест «процедурный слот во всех каналах» |
| 4 | `atlas.rs`: страница `RGBA8` `page_px²` (параметр, по умолчанию 2048), сетка слотов, `slot_of(cp) -> Option`, `ensure(cp, style) -> slot` (промах → растеризация в канал), маска готовых стилей, `pixel(slot, x, y, style)` с учётом `style_source`, сброс при переполнении, список «грязных» прямоугольников для будущей загрузки в GL | тесты: промах/попадание, ленивые каналы, переполнение → сброс, O(1) чтение |
| 5 | `soft_backend.rs`: `ensure` перед отрисовкой строки, стиль ячейки, осветление при `BOLD` сохраняется | пиксельные тесты Bold/Italic/BoldItalic против атласа |
| 6 | `app.rs`/`demo.rs`: загрузка семейства, строки с `BOLD`, `ITALIC`, `BOLD|ITALIC`; удалить `.fnt`-логику, `.gitignore` | `cargo run` |
| 7 | ТЗ: FR-3 (+ITALIC, BOLD = глиф + осветление), FR-8…FR-11 (без `.fnt`), FR-9/§6.3 (`RGBA8UI`, динамика, страница), §7.3 (канал по стилю), NFR-6 (оговорка), §13; `AGENTS.md`, `PROJECT_MAP.md`, ADR-0001 — пометка «частично заменён ADR-0003» | grep «.fnt», «fnt_path» |
| 8 | Гейты; golden перегенерировать (сцена + Bold/Italic); размер release (`cargo bloat --crates`) | отчёты `docs/done|test|verify` |
