Статус: **выполнен 2026-11-12** — см. `docs/done/2026-11-12-checkbox.md`. Отклонений от плана нет. После выполнения владелец изменил О2: `Enter` переключает флажок так же, как пробел — правка `checkbox.rs`, теста К1, ADR-0031 и документов.

## Факты по коду (проверено 2026-11-12)

- `widgets/button.rs`: `ButtonState { node, enabled, pressed, event }`; мышь — `Down` (левая) → `pressed`, `Up` при `pressed` → активация, если внутри `node.area`, `Cancel` → сброс, `Move` при `pressed` → `Yes`; стиль: неактивная → нажата → фокус → обычная.
- `control.rs:86` — `WidgetEvent::{Selected, Activated, Changed, Submitted}`; единственный `match` по нему — `ui/element.rs::Stateful::emit`; привязки — `Element::bind_*` и `Ui::on_*` (`ui/mod.rs`).
- `ui/mod.rs:72` — `Ui::group(block, layout, children)`, `Ui::focus_style`.
- `buffer.rs`: `set_string(x, y, text, style, clip)`, `set_line(area, &StyledLine, skip)`, `set_style(area, style)`.
- `examples/widget_edit.rs`: форма — `Ui::group` высотой 12 строк, сообщения `Msg`, `update`, «Сброс» очищает состояния.
- Базовый прогон — коммит `237344a`: 277 тестов.

## Проектные решения (зафиксированы в ADR-0031)

1. **`widgets/checkbox.rs`**: `CheckboxState { node, enabled, checked, pressed, event }` — `new`, `with_checked(bool)`, `disabled`, `is_checked`, `set_checked`, `toggle` (обе без события); действие пользователя — внутренний переключатель с `WidgetEvent::Toggled(новое)`. `Control`: пробел → `Yes`; мышь — как у кнопки. `Checkbox<'a>`: `new(label)`, `marks(checked, unchecked)`, четыре стиля; отрисовка — метка, пробел, подпись в средней строке области.
2. **`WidgetEvent::Toggled(bool)`**, `Element::bind_toggle`, `Stateful::on_toggle`, `Ui::on_toggle`.
3. **Пример `widget_edit`**: группа «Параметры» (`Ui::group`) с флажками «скрытый» и «только чтение», сообщения `Msg::Hidden(bool)`/`Msg::ReadOnly(bool)`, значения — в итоге «Применить», «Сброс» снимает.

Уточнение к ТЗ: конструктор отмеченного флажка — `with_checked(bool)` (в ТЗ `checked(bool)` — совпало бы с именем поля).
