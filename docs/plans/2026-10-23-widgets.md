# План: набор виджетов `gterm-widgets`, часть 1

Статус: **часть 1 реализована 2026-10-23** — см. `docs/done/2026-10-23-widgets.md`; отклонений от плана нет (О1 — `ScreenBuffer` как буфер, О2 — жадная раскладка, О3 — часть 1: `Block`, `Paragraph`, `List`, `Table`, `Popup`; О4 — отдельный крейт). Часть 2 (`Tabs`, `Gauge`, `LineGauge`, `Scrollbar`, `Clear`) — отдельной задачей.

- **ТЗ задачи:** `docs/spec/2026-10-23-widgets.md`.
- **Решения:** ADR-0023 (`docs/adr/0023-widgets-crate.md`).
- **Опирается на:** ADR-0013 (цвета с альфой), ADR-0014 (`DrawCtx::draw_buffer`, `ScreenBuffer::transparent`), ADR-0017 (workspace), ADR-0022 (процедурные рамки пяти видов).

## Факты по коду (проверено 2026-10-23)

- `ScreenBuffer`: `cols()/rows()`, `cell(col, row) -> Cell`, `set_cell(col, row, ch, fg, bg, flags)` (за пределами — без паники? — проверить: `fill_rect` обрезает по `cols`/`rows`, `set_cell` — `assert`), `fill_rect(col, row, w, h, ch, fg, bg, flags)` с обрезкой, `with_default_colors`, `transparent`, `default_colors()`, `set_background`. `Cell { ch: char, fg, bg, flags }`, `'\0'` — пустая ячейка. `Color(u32)` `0xAARRGGBB`, `from_rgb/from_rgba/a()`, константы `TRANSPARENT`, `BLACK`, `WHITE`, `GREEN`, `MAGENTA`, `CYAN`. `CellFlags::{BOLD, ITALIC, UNDERLINE}` (`bitflags 2`).
- `DrawCtx::draw_buffer(&ScreenBuffer, col: i32, row: i32)`, `grid() -> Grid { cols, rows }` — наложение живёт один кадр, вызывается из `on_redraw`.
- ratatui 0.30 (исходники): `Widget::render(self, area: Rect, buf: &mut Buffer)`, `StatefulWidget::render(self, area, buf, state)`, `Rect { x, y, width, height }: u16`, `Layout::{vertical, horizontal}(constraints).split(area) -> Rc<[Rect]>`, `Constraint::{Length, Percentage, Ratio, Min, Max, Fill}`, `ListState { offset, selected }`, `TableState` аналогично.

## Проектные решения (зафиксированы в ADR-0023)

1. Крейт `crates/gterm-widgets` зависит от `gterm` и `bitflags`; `winit` — только `dev-dependency` для примера.
2. Буфер — `ScreenBuffer`; рисование через расширение-трейт `BufferExt` (`set_styled`, `set_string`, `set_style`, `fill`) с обрезкой по `Rect` и границам буфера; `Rect` в `u16`, как у ratatui.
3. `Style { fg: Option<Color>, bg: Option<Color>, add: CellFlags, remove: CellFlags }` — `patch` и применение к `Cell`; цвета с альфой проходят как есть.
4. Текст: `Span { content: Cow<str>, style }`, `Line { spans, style, alignment }`, `Text { lines, style, alignment }`; ширина — число символов (одна кодовая точка = ячейка); перенос `Wrap { trim }` по словам, слова длиннее строки — по символам.
5. Раскладка: `Layout { direction, constraints, margin, spacing }` → `Vec<Rect>`; жадно: `Length`/`Percentage`/`Min` фиксируют стартовые длины, нехватка урезается с конца; остаток: сначала `Max` до своих пределов поровну, потом `Fill` по весам, при отсутствии `Fill` — `Min` поровну; остаток целочисленного деления — первым элементам.
6. Виджеты части 1: `Block` (заголовки сверху/снизу с выравниванием, `Borders`, `BorderType::{Plain, Rounded, Double, Thick}`, `Padding`, стили рамки и фона, `inner()`), `Paragraph` (`Text`, `Block`, `Wrap`, выравнивание, `scroll`), `List`/`ListState` (многострочные пункты, символ и стиль выделения, автосмещение), `Table`/`TableState` (ширины через `Layout`, заголовок, зазор, выделение), `Popup` (прямоугольник на сетке + прозрачный буфер с фоном по альфе; рисуется `DrawCtx::draw_buffer`).
7. Пример `examples/widgets.rs`: системный шрифт, `FixedGrid`, слева `List`, справа `Table` и `Paragraph` с переносом, снизу строка подсказки; `Tab` — фокус, стрелки — выделение, `p` — полупрозрачный `Popup`, `Esc` — выход.

## Шаги

1. Основа: манифест, `lib.rs`, `geometry`, `style`, `text`, `buffer`, трейты; тест `buffer`/`text` (обрезка по `Rect`, перенос).
2. Раскладка + тесты таблицей случаев.

8. ADR-0023 + индекс, ТЗ 1.19 (§1, §5.1, §13), `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`, отчёты.

## Риски

- `set_cell` за пределами буфера может паниковать — все вызовы идут через `BufferExt` с обрезкой.
- Жадная раскладка отличается от солвера ratatui на противоречивых ограничениях — правила зафиксированы тестами.
