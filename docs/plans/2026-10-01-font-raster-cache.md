# План: этап 2 по ТЗ 1.1 — растр шрифта из TTF с кэшем `.fnt`

- **ТЗ:** `docs/TZ_terminal_emulator.md` §3.2 (FR-8…FR-11), §12 этап 2. Отдельного `docs/spec/` нет — ТЗ проекта и есть постановка.
- **Решение:** `docs/adr/0001-runtime-font-raster-cache.md` (Accepted).
- **Рамки:** модуль шрифта + минимальная адаптация call-sites в бэкендах, чтобы `cargo clippy --all-targets [--features gl]` и `cargo test` оставались зелёными. **Не входит:** переделка Software-рендерера под §7.3/§8 (этап 3), окно, GL-шейдер, демо.

## Открытые решения

Нет — все выборы сделаны владельцем (рантайм, `assets/` рядом с exe, TTF из репозитория; все глифы BMP вместо кодовой страницы, нет глифа → пустая ячейка — уточнение 2026-10-01).

## Шаги

| # | Шаг | Проверка |
|---|---|---|
| 1 | `Cargo.toml`: `fontdue` без default-features; `.gitignore`: `assets/*.fnt`; удалить битый `assets/font_8x16.bin` | `cargo build` |
| 2 | `src/font.rs`: константы `FONT_FILE`/`FONT_SIZE_PX`, `FntHeader`, `FontData` (заголовок + таблица слотов + 1bpp растр), сериализация `.fnt` (FR-8.3), `Atlas::from_font_data` с таблицей «кодовая точка → слот» O(1), доступ к пикселю без аллокаций | тесты round-trip, позиции слотов, поиск слота |
| 3 | ~~`codepage.rs`~~ — упразднён: в растр входят все глифы BMP, кодовой страницы нет | тест: `А` (U+0410) и `─` (U+2500) → непустые глифы, U+FFFF → слот 0 |
| 4 | `src/font_gen.rs`: `find_assets_dir`, FNV-1a, `rasterize` (fontdue, порог 50 %), `load_or_generate` с правилом пересоздания FR-8.2 и статусом кэша (FR-8.5) | тесты во временном каталоге: нет файла → создан; совпал → не перезаписан; иной размер/версия/хеш → пересоздан; битый → пересоздан; детерминизм |
| 5 | Бэкенды принимают `Atlas` в конструкторе вместо вызова глобального `atlas()`; `main.rs` загружает шрифт и печатает размер глифа/статус кэша, код ≠ 0 при ошибке | `cargo run`; `cargo test --features gl` |
| 6 | `cargo fmt --check`, `clippy --all-targets` (обе конфигурации), `cargo test`; `cargo bloat`-замер вклада `fontdue` — при наличии инструмента | отчёт `docs/done/`, `docs/test/`, `docs/verify/` |
