## Факты по коду (проверено 2026-11-18)

- `style.rs`: `Style { fg, bg, add, remove }` — частичная заплатка, `a.patch(b)` — заданное в `b` побеждает. Поэтому «тема под явным стилем» = `тема.patch(явный)`; отличать «не задан» от «задан пустым» не требуется.
- `ui/mod.rs`: описание `Ui` хранит виджеты до `render` (`Stateless.widget`, `Stateful.widget` — `Option<W>`), рамки контейнеров — `Kind::Container.block`; `hotkeys`/`clipboard`/`modal` дочернего описания поднимаются к корню в `Ui::container`. `Ui::render` → `Element::render(area, buf)`.
- `ui/modal.rs`: `Modal::render(screen)` заливает буфер `Popup::style` и рисует содержимое — вложенное `Ui`.
- `combo_box.rs`: слой выпадающего списка — `Modal::below(...).style(widget.style)` + `Ui::owned(DropdownList)` (`Drawable`).
- Трейты `Widget`, `StatefulWidget`, `Drawable` реализуют и приложения (`examples/widgets.rs`); `List` и `Table` реализуют и `Widget`, и `StatefulWidget`.
- Все виджеты начинают с `buf.set_style(area, self.style)` и пишут текст поверх ячеек: незаданные `fg`/`bg` берутся из того, что уже лежит в буфере.
- `toml` 1.2.1: MIT OR Apache-2.0, MSRV 1.85, фичи `std` + `parse` без `serde`.
- Базовый прогон (коммит `b6e03ae`): 307 тестов, 0 падений.

## Проектные решения (зафиксированы в ADR-0037)

1. **Модуль `src/theme/`**: `mod.rs` — `Theme` (области `BTreeMap<String, Style>`, палитра, предупреждения), доступ `get` / `style` (наследование по точке) / `first` (первая из перечня, точные имена) / `color` / `scopes` / `base`, правка `set` / `set_color`, встроенная `Theme::default()`; `load.rs` (за фичей `theme-toml`) — разбор TOML, цвета, `inherits`, `ThemeError`.
2. **Неявная доставка.** `Ui::theme(&'a Theme)` — поднимается к корню, как карта сочетаний. `Ui::render` с темой: накладывает на свою область базовый стиль (`fg` из `ui.text`, `bg` из `ui.background`), красит рамки контейнеров и передаёт тему каждому элементу; `Modal::render` — базовый стиль слоя из `ui.popup` и та же тема содержимому.
3. **Виджет знает свои области.** У трейтов `Widget`, `StatefulWidget`, `Drawable` — метод по умолчанию `apply_theme(&mut self, &Theme)` (пустой): дерево зовёт его перед отрисовкой. Встроенные виджеты подставляют стили темы под свои явные; тот же код доступен явно — `.themed(&theme)`. Свои виджеты приложения собираются без правок.
4. **Области и запасные цепочки** — таблица в ADR-0037 (свои области `ui.button.*`, `ui.checkbox.*`, `ui.input.*`, `ui.combo.*`, `ui.list.*`, `ui.table.*`, `ui.tabs.*`, `ui.scrollbar.*`, `ui.gauge.*`, `ui.window.focus` с откатом к областям helix). Текст своих областей не имеет: он берёт базовый стиль области, на которой лежит.
5. **`reversed`** разрешается при загрузке: недостающий цвет области берётся из `ui.text` / `ui.background`, цвета меняются местами; нет обоих — предупреждение.
6. **Формат:** helix + `#RRGGBBAA`; неотображаемые модификаторы — в `warnings()`.

## Шаги

1. **Зависимость и её цена.** `toml` в `gterm-widgets/Cargo.toml` за фичей `theme-toml`; замер release до и после. Проверка: размеры `widgets.exe` / `widget_edit.exe`; при неприемлемом приросте — стоп и вопрос владельцу (ТЗ, О3).
2. **`Theme` без файлов.** `theme/mod.rs`, экспорт в `lib.rs`; тесты `tests/theme.rs` (К3, К6).
3. **Загрузка.** `theme/load.rs`; тестовые темы `tests/data/themes/`; тесты `tests/theme_load.rs` (К1, К2, К4, К7). Проверка шагов 2–3: `cargo test -p gterm-widgets`.
4. **Дерево и виджеты.** `apply_theme` у трейтов, `Ui::theme`, `Modal`, все виджеты; тесты `tests/theme_widgets.rs` (К5). Проверка: `cargo test -p gterm-widgets`.
5. **Пример и свои темы.** `examples/themes/gterm_dark.toml`, `gterm_light.toml`; `widget_edit` — тема вместо констант, `--theme-dir`, `--theme`, смена на лету; снимки окна `tools/shot.ps1` (К8).
6. **Документы и гейты.** ТЗ проекта §13, `AGENTS.md`, `PROJECT_MAP.md`, оба README, `TODO.md`, отчёты `docs/done|test|verify/`; `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, полный `cargo test`; размеры release (К9).

## Риски

- Сигнатура внутреннего `Element::render` меняется — все четыре реализации в `ui/element.rs` правятся в шаге 4.
- `Ui::render` с темой перекрашивает свою область базовым стилем: приложение, красившее фон само, увидит цвета темы — только если тему подключило.
- На части тем helix запасные цепочки дают малоконтрастные кнопки и рамки (ТЗ §5).
