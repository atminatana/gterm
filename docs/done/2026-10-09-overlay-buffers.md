## Отклонения от плана

- **Ускорение Software** (не было в плане, понадобилось по замеру шага 7). Попеременные запуски с закоммиченным кодом показали: без наложения 81–85 → 63–65 FPS. Причина — у `Atlas::pixel` и `fade` появилось второе место вызова, и при `opt-level = "z"` они перестали встраиваться: деление в `slot_origin` и поиск канала выполнялись на каждый пиксель. Исправлено:
  - `#[inline(always)]` у `Atlas::pixel`, `slot_origin`, `blend`, `fade`, `mul`, `over`, `composite`;
  - `div255` вместо деления на 255 — точное тождество, проверено перебором;
  - два быстрых пути в `draw_overlay_cell`.

  Итог без наложения — 102–104 FPS, быстрее, чем до задачи. Попутно снята регрессия ≈ 14 % из задачи про альфу (ADR-0013).
- **`atlas.rs`** изменён вне файлов плана: только атрибуты `#[inline(always)]` с комментарием. Без этого Software без наложения медленнее на 22 % (замер выше).
- **Режим замера** — флаг `--overlay` у `demo --bench`.

## Блоки завершения (BP-11)

**COMPLETENESS.** Требования ТЗ задачи §3–§4 реализованы и покрыты тестами:
- формулы и тип `Overlay` — `tests/overlay.rs`;
- кадр Software, частичный кадр, атлас — там же;
- GL ↔ Software — сцена `overlay 16px`;
- `on_redraw` — оконный тест.

Пример `overlay` сделан; проверка глазами — за владельцем.

**CORRECTNESS.**
- Golden-эталоны не менялись: без записей кадр прежний.
- Ожидаемые значения пиксельных тестов посчитаны вручную и сверены отдельным расчётом; свойства формул проверены перебором.
- Две мутации шейдеров — без наложения в основном проходе и без фона записи в `overlay.frag` — ловятся сценой `overlay 16px`; шейдеры восстановлены из копий.
- Ускорения Software проверены полным прогоном: golden, 8 сцен GL ↔ Software.

**EVIDENCE.**
- fmt и clippy `--all-targets` — чисто.
- `cargo test` — 151 тест harness (+18 в `tests/overlay.rs`), 4 оконных бинарника и 5 сценариев `stage8_faults` — `ok`.
- `stage4_gl` — identical, 8 сцен на GL 3.3 и GLES 3.0.
- `overlay` запущен на 6 с на GL 3.3, GLES 3.0 и Software, stderr без ошибок.
- Размер release: `demo.exe` 1 454 080 Б, `full_table.exe` 1 447 424 Б, `overlay.exe` 1 442 816 Б.
- Замеры — `docs/test/…`.

**⚠ WARNINGS.**
- **Software с полупрозрачным наложением на весь экран — 23,6 FPS при NFR-5 ≥ 60** (сетка 120×40, каждая ячейка записи с альфой фона и символа). Три попытки ускорения сделаны (встраивание, `div255`, быстрые пути: 9,9 → 23,6 FPS); дальше — отдельная задача (`TODO.md`). Это худший случай; небольшие записи стоят пропорционально площади.
- **Профиль `opt-level = "z"` (§10.2) стоит Software в 2–3 раза.** Справочная сборка с `opt-level = 3`: 219 FPS без наложения и 47,3 с наложением. Менять ли профиль — решение владельца.
- **GL с наложением на весь экран:** CPU-часть кадра 1,24 мс. NFR-4 (≤ 1 мс) задан для кадра без наложения; без наложения — 0,66 мс.
- **`gl_backend.rs` — 1 262 строки** (сигнал QG-06). Обоснование: это одна обязанность (GL-бэкенд), а весь `unsafe` по NFR-9 и `AGENTS.md` обязан жить в этом файле, поэтому разбиение потребовало бы менять правило проекта. Предложение — отдельной задачей, если владелец захочет.
- **Глазами не проверено** (§11.3): `cargo run --bin overlay` на трёх бэкендах.
- **Проверено только на NVIDIA GTX 1060.** Неполный FBO `RGBA8UI` на других драйверах даст `RenderError` и откат на Software — не проверено (этап 8).
