## CORRECTNESS

Каждый тест частичного кадра сравнивает кадр с кадром нового рендерера, нарисованным с нуля, — то есть проверяет результат, а не только полосы. Мутационная проверка: если отключить перерисовку строк с `BLINK`, падают 4 из 8 новых тестов (остальные четыре этот путь не затрагивают); код возвращён.

- `cargo fmt --check` ✓; `cargo clippy --all-targets -- -D warnings` ✓; `cargo test` — **131 тест** (+8) + 4 оконных бинарника (`stage8_faults` — 5 сценариев) — всё ok; `stage4_gl`: `GL ↔ Software identical, 6 scenes` на OpenGL 3.3 и OpenGL ES 3.0.
- **Цена кадра смены фазы** (release, сцена демо 80×25, шрифт 22 px, окно 1040×725 = 754 000 пикс, одна строка с `BLINK`, 400 кадров; временный пример, удалён): полный кадр — 6,095 мс (так стоила смена фазы до ADR-0010); смена фазы — **0,226 мс**, перерисовано 30 084 пикс/кадр. Тот же замер на коде до правок (рабочее дерево `3586ca6`): смена фазы — 6,305 мс, полный кадр — 6,416 мс; на новом коде полный кадр — 5,922 мс (без регрессии).
- **`--bench --backend=soft`**, A/B поочерёдно с версией до правок (`cpu`, среднее): до — 9,80 / 9,81 / 9,80 / 10,02 / 10,87 мс; первый вариант частичного вывода (построчное копирование) — 12,01 / 11,99 / 12,55 мс (**регрессия ~22 %**); тот же код с принудительным полным выводом — 9,58 / 9,76 мс; итоговый (полоса во всю ширину — одним куском) — **9,71 / 9,61 мс**.

## ⚠ WARNINGS

- Глазами не проверено (§11.3): мигание и ввод в окне на Software; X11 без композитора (перекрыть окно и открыть — ADR-0010 п.4); Wayland (`age = 2` → полный вывод) — пункт в `TODO.md`.
- Если системная перерисовка совпадёт со своим запросом кадра, winit сольёт их в один `RedrawRequested`, и кадр выведется частично; на X11 без композитора открытая часть окна может остаться неотрисованной до следующего полного вывода. Устранимо только отдельным признаком от системы (в winit 0.30 его нет).
- Почему построчное копирование в буфер окна замедляло следующий `render`, не выяснено — найдено и устранено замером; узкие полосы (сетка уже окна) по-прежнему копируются построчно, они малы.
- Замечено вне задачи: на тике мигания `App` перерисовывает кадр, только если обработчик сам запросит (`app.rs`, `about_to_wait`; `on_tick` по умолчанию пуст) — приложение без своего `on_tick` мигания не увидит. Не менялось; предлагается отдельной задачей.
- `app.rs` (1173 строки) — превышение порога QG-06 унаследовано; разделение — отдельной задачей.
- Изменения не закоммичены — коммит по запросу владельца.
