# Отчёт о выполнении: комбинации клавиш — модуль `gterm::hotkey`, запись/разбор, трекер, пример `hotkeys`

- **Задача:** `2026-10-30-hotkeys`. ТЗ — `docs/spec/2026-10-30-hotkeys.md` (утверждено 2026-10-30), план — `docs/plans/2026-10-30-hotkeys.md`.
- **Решение и его ПОЧЕМУ:** ADR-0028.

## Что сделано

| Шаг плана | Результат |
|---|---|
| 1. Модуль | `crates/gterm/src/hotkey.rs`: `Key` (`Ctrl`/`Alt`/`Shift`/`Super`/`Code(KeyCode)`, `from_event` по `physical_key`, `from_code` сводит левый/правый, `name`/`parse_name` по таблице всех 194 вариантов `KeyCode` через макрос `key_names!` с псевдонимами `A`–`Z`, `0`–`9`, `Up`/`Down`/`Left`/`Right`, `Esc`; разбор принимает и псевдоним, и имя варианта, регистр не важен); `Hotkey` (`alts`/`Seq`/`Node`, `empty`/`key`/`chain`, `is_empty`, `keys`, `matches`, канонизация модификаторов, `Display` с правилом скобок, `FromStr` рекурсивным спуском, `ParseError { position, kind }`); `HotkeyTracker` (`full`/`held` с путями, `feed`/`feed_key`, `current`/`full`/`is_active`/`reset`, `HotkeyEvent { hotkey, complete }`); `lib.rs` — `pub mod hotkey` |
| 2. Тесты | `crates/gterm/tests/hotkey.rs` (7): круговая запись примеров постановки, имена и канонизация, ошибки с позицией, `matches`, сценарий владельца шаг за шагом, вложенный сценарий/повтор/шум/`reset`, `Key::from_code` |
| 3. Отпускания | `app/events.rs`: фильтр `Pressed` снят — `on_key` получает оба состояния; `gterm-widgets/src/ui/route.rs`: `Ui::key` на `Released` → `Routed::ignored()` |
| 4. Пример | `crates/gterm/examples/hotkeys.rs`: `FixedGrid` 72×16, строки «сейчас»/«полная»/«последняя», журнал четырёх сигналов, шесть образцов из строк с отметкой совпавших, `Esc` при пустом трекере — выход; запуск с инжекцией — код 1 после повтора кадра |
| 5. Документы | ADR-0028 (уточнён правилом скобок и псевдонимами) + индекс; ТЗ 1.23 (§13); `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`; отчёты `test`/`verify`; размеры release |

Уточнения при реализации (в статусе плана и ADR): правило скобок — без скобок продолжение ряда модификаторов и линейная цепочка, иначе группа в скобках (`Space+[Ctrl+[K,U]]` как в постановке); имена сканируются как любые буквы и цифры Unicode, поэтому `Ctrl+Ж` даёт «неизвестная клавиша».
