- **Задача:** `2026-11-12-checkbox`. ТЗ — `docs/spec/2026-11-12-checkbox.md` (утверждено 2026-11-12), план — `docs/plans/2026-11-12-checkbox.md`.

## CORRECTNESS
- Тесты прошли с первого прогона, поэтому проверены пятью мутациями (исходники восстановлены побайтно, полный прогон после восстановления зелёный): `Enter` не переключает → 1 падение; отпускание снаружи переключает → 1; стиль неактивного игнорируется → 1; программный `toggle` даёт событие → 1; `Toggled` не публикуется → 2.

## ⚠ WARNINGS
- Вид примера проверен исполнителем 2026-11-12 по снимкам окна `widget_edit` на OpenGL 3.3 (Windows): группа «Параметры» с двумя флажками в одну строку; после набора текста, четырёх `Tab`, пробела, `Tab` и `Enter` — оба флажка отмечены, рамка группы подсвечена, в статусе «только чтение: да». Клик мышью по флажку на окне не проверялся; проверка по бэкендам для виджетов не требуется (решение владельца 2026-11-12).
- Обход `Tab` и подсветка рамки группы проверены в тесте на своей раскладке, не на раскладке примера.
- Новый вариант публичного `WidgetEvent::Toggled` — внешний исчерпывающий `match` по перечислению перестанет собираться.
- Не делалось по решению владельца: переключатели «один из многих», третье состояние, блокировка группы целиком.
- Коммит и пуш сделаны по запросу владельца 2026-11-12, до его проверки вида примера глазами.
