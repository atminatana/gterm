# Отчёт о выполнении: растяжение глифов псевдографики под ячейку (вариант Б)

- **Задача:** `2026-10-23-box-glyph-fit`. ТЗ — `docs/spec/2026-10-23-box-glyph-fit.md`, план — `docs/plans/2026-10-23-box-glyph-fit.md`.
- **Решение и его ПОЧЕМУ:** ADR-0020. Предыстория: вариант А (ADR-0019) проверен владельцем глазами, отклонён и откачен в этот же день.

## Что сделано

| Шаг плана | Результат |
|---|---|
| 1. Библиотека | `rasterizer.rs`: `rasterize_font_glyph(…, fit_to_cell, …)` (`:241`) — для рамок в `Font`/`Combined` контур берётся без хинтинга (`DrawSettings::unhinted`, `:269`) и вписывается в ячейку функцией `fit_commands_to_cell` (`:309`): `x' = x · w / advance`, `y' = (baseline − h) + (y − descent) · h / (ascent − descent)`; `rasterize` передаёт `is_box` как флаг |
| 2. Тест | `tests/box_drawing_mode.rs::font_box_glyphs_reach_cell_edges`: краска `─` одинакова в колонках 0, середина, край; `│` — в строках 0, середина, край; края `┼` равны краям `─` и `│` |
| 3. Пример | без изменений кода — сравнение `q`/`w`/`e`; запуск с `--backend=soft --fail-frames=2` рисует кадр |
| 4. Документы | ADR-0020 + индекс; ТЗ 1.16 (FR-8.4); `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`; отчёты `test`/`verify` |

Отклонение от ТЗ (допущение «хинтинг не отключается»): с хинтованным контуром вертикальный стык не смыкался — нижняя строка `│` получала 177 единиц краски против 267 у остальных (хинтер округляет конец штриха к сетке номинального размера). Без хинтинга краска равномерна: `─` — 378 в каждой колонке, `│` — 329 в каждой строке. Решение принято как обратимое и записано в ADR-0020 п.3; цена — дробная толщина линий (сероватые при малых размерах).

## ⚠ WARNINGS
- Глазами — за владельцем: стыки `─`/`│` и толщина линий в `w`/`e` против `q`. Линии без хинтинга дробной толщины; если это хуже зазоров, обратный ход — вернуть хинтинг для рамок (одна строка) и искать другой путь.
- Шрифты, рисующие `│` короче `descent…ascent` намеренно, сохраняют уменьшенный зазор.
- Ветка «в шрифте нет глифа» для вписывания не актуальна (путь шрифта не вызывается), прежнее предупреждение ADR-0018 остаётся.
- Коммит не делался; в рабочем дереве также документы отклонённого варианта А (ADR-0019 Rejected) и откат его кода до `HEAD`.
