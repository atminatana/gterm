# Отчёт о выполнении: полная запись темы, сохранение в примере `theme`

- **Задача:** `2026-11-23-theme-save`. Постановка владельца 2026-11-23 в чате: «возможность полного сохранения текущей темы, включая вычисленные цвета… чтобы создавался файл, который можно править или взять за основу для доработки».
- **Этапы ТЗ, плана, отчётов `test` / `verify` не оформлялись отдельными файлами:** задача выполнена напрямую как небольшое дополнение к `2026-11-23-theme-roles` (одна функция библиотеки и окно в примере); сведения о тестах и проверке — здесь. Решение о сокращённом цикле принял исполнитель, не владелец, — см. WARNINGS.
- **Решение и его ПОЧЕМУ:** ADR-0038, поправка 2026-11-23.

## ⚠ WARNINGS
- **Цикл задачи сокращён исполнителем.** ТЗ и план не писались, владельца об этом не спрашивал: счёл задачу небольшим дополнением. Если нужны отдельные ТЗ и отчёты — оформлю.
- **Каталог по умолчанию.** Без ключа `--theme-dir=` первый каталог перечня — `examples/themes/` репозитория: сохранённый туда файл окажется в рабочем дереве git. Путь в окне можно изменить; в `.gitignore` ничего не добавлялось.
- **Запись плоская.** `inherits`, комментарии исходного файла и то, что загрузка пропустила с предупреждением (`dim`, цвет подчёркивания и т. п.), в запись не попадают; `reversed` записан уже обменянными цветами.
- В записанном файле правка основы (`ui.background`, `ui.accent`) не меняет тона и области виджетов — они заданы; чтобы вернуть вывод, их строки удаляют. Это сказано в заголовке файла.
- Если несколько имён палитры несут один цвет, в запись идёт первое по алфавиту (в `sniffnet_nord_dark` у `ui.accent` — `primary` вместо `text_headers`): цвет тот же, имя другое.
- `Style::remove` (снятие флагов) не записывается — у тем из файлов его нет; у темы, собранной в коде с `remove`, круговая проверка не сойдётся.
- В окне сохранения сочетания `F2`/`F3` отключены намеренно: смена темы разошлась бы с именем файла в поле.
- `examples/theme/main.rs` — 499 строк, на границе ориентира 500: экран, сообщения и обработчики одного окна; следующее расширение примера потребует выноса (например, обработки сообщений) в отдельный модуль.
- Не проверялось: Linux, мышь в окне сохранения, запись в каталог без прав; время полного прогона runner не суммирует — не измерено.
- Общий коммит с задачей `2026-11-23-theme-roles` и пуш в `origin/master` — по запросу владельца 2026-11-23.
