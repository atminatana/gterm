## CORRECTNESS
- Тесты обеих частей прошли с первого прогона, поэтому проверены мутациями (исходники восстановлены побайтно, прогон после восстановления зелёный).
- Тик, 4 мутации: срок от прежнего срока (догонка) → падение сценария `period`; тик всегда запрашивает кадр → `period`; выключение периода игнорируется → `switch`; тики без периода → `no-period`.
- `Meter`, 5 мутаций: зона по уровню, а не по месту ячейки → 3 падения; половина ячейки не рисуется → 3; пик не рисуется → 1; половинная ячейка берёт стиль заполненной → 1; заливается только первая строка → 1.

## ⚠ WARNINGS
- `examples/widgets.rs` — 501 строка, ориентир QG-06 (500) пересечён этой задачей (+20 строк). Файл делает одно дело — показывает все виджеты на одном экране одним описанием `ui()`; делить его ради числа не стал.
- Тик на Linux (X11, Wayland) автоматически не проверялся: хост разработки — Windows. Пункт в `TODO.md`.
- Точность тика сверху не проверяется и не гарантируется (системный таймер); тест проверяет только «не раньше срока».
- Сценарий `period` считает, что к шестому тику (120 мс) стартовые кадры окна уже отрисованы; на очень медленной машине это допущение может не выполниться.
- В `AGENTS.md` осталась унаследованная фраза «`Cargo.lock` есть, но репозиторий без коммитов» — вне рамок задачи, не трогал.
