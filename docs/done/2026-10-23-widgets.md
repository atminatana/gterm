# Отчёт о выполнении: набор виджетов `gterm-widgets`, часть 1

- **Задача:** `2026-10-23-widgets` (часть 1 по О3). ТЗ — `docs/spec/2026-10-23-widgets.md`, план — `docs/plans/2026-10-23-widgets.md`, исследование — `docs/research/2026-10-23-ratatui-backend.md`.
- **Решение и его ПОЧЕМУ:** ADR-0023.

## Что сделано

| Шаг плана | Результат |
|---|---|
| 1. Основа | `crates/gterm-widgets/`: `Cargo.toml` (зависимости `gterm`, `bitflags`; `winit` — dev), `lib.rs`, `geometry.rs` (`Rect`, `Margin`), `style.rs` (`Style` с `patch`/`apply`), `text.rs` (`Span`/`Line`/`Text`, `StyledLine`, `wrap_line`), `buffer.rs` (`BufferExt` для `ScreenBuffer`), трейты `Widget`/`StatefulWidget` |
| 2. Раскладка | `layout.rs`: `Layout`/`Constraint`/`Direction`, жадный алгоритм по плану (стартовые длины, урезание с конца, `Max` → `Fill` → `Min`, остаток первым) |
| 3–5. Виджеты | `widgets/block.rs` (`Borders`, `BorderType` ×4, заголовки сверху/снизу по выравниванию, `Padding`, `inner`), `paragraph.rs` (`Wrap`, выравнивание, `scroll`, `line_count`), `list.rs` (`ListItem`, `ListState`, автосмещение к выделению), `table.rs` (`Row`, `TableState`, ширины через `Layout`, заголовок, зазор, выделение) |
| 6. Popup | `widgets/popup.rs`: `Popup::centered`, прозрачный буфер с фоном по альфе (подложка `TRANSPARENT`), `draw` через `DrawCtx::draw_buffer` |
| 7. Пример | `examples/widgets.rs`: список, таблица с двойной рамкой, абзац с переносом в жирной рамке, подсказка; `Tab`, стрелки, `p`, `Esc`; системный шрифт 14 px, сетка 90×28; запуск с `--backend=soft --fail-frames=2` рисует кадр |
| 8. Документы | ADR-0023 + индекс; ТЗ 1.19 (§1, §5.1); `AGENTS.md`, `PROJECT_MAP.md`, `TODO.md`; отчёты `test`/`verify`; workspace — третий член |

Отклонений от плана нет. Уточнение по обрезке: область виджета пересекается с экраном до отрисовки (как у ratatui) — у блока, частично вышедшего за экран, рамка рисуется по обрезанной области; зафиксировано тестом.

## COMPLETENESS
- Каждый виджет части 1 — код и тест по текстовому снимку (`tests/widgets.rs`, 6 тестов); раскладка — 4 теста таблицей случаев; текст — 4 теста; окно — 2 теста (альфа буфера, смешение в Software).
- Пример — код; запуск с инжекцией; глазами (К5) — за владельцем.
- `gterm` не изменён (К1): `git diff --stat crates/gterm` пуст; его тесты и golden прежние.

## CORRECTNESS
- Мутации (исходник восстановлен, прогон после восстановления зелёный): список без подгонки смещения → падает `list_highlights_and_scrolls_to_selection`; раскладка без распределения остатка → падает `length_and_fill`.
- Смешение окна проверено на Software с шрифтом репозитория: пиксель пустой ячейки под окном отличается и от фона экрана, и от цвета окна, каждый канал — между ними; пиксель вне окна прежний.
- Полный `cargo test` — все три пакета.

## EVIDENCE
- Гейты после последнего изменения кода: `cargo fmt --check` чисто, `cargo clippy --all-targets -- -D warnings` чисто (три пакета, примеры включены), `cargo test` — **199 тестов** harness (183 + 16), 0 падений, 4 оконных бинарника ok; golden без изменений.
- Размер release: пример `widgets.exe` 1 186 816 Б; `demo.exe` 1 540 608 Б — без изменений (крейт в него не входит).
- LOC: библиотека крейта 1 892 (`text.rs` 300, `block.rs` 290, `table.rs` 277, `list.rs` 260, `layout.rs` 186, `paragraph.rs` 142, `buffer.rs` 109, `geometry.rs` 109, `style.rs` 87, `popup.rs` 73, `lib.rs` 30, `widgets/mod.rs` 29), пример 279, тесты 548; итого 2 719.
- Проверочный проход BP-09: заново открыты 6 мест — `wc -l`, `git diff --stat crates/gterm`, выводы `cargo test` трёх пакетов, вывод мутаций, `ls -l target/release`, индекс ADR. Отброшенных находок нет.

## ⚠ WARNINGS
- Глазами — за владельцем: `cargo run -p gterm-widgets --example widgets` на трёх бэкендах.
- Часть 2 (`Tabs`, `Gauge`, `LineGauge`, `Scrollbar`, `Clear`) и графики на мозаиках — отдельные задачи (`TODO.md`).
- Нет графем и двухшириных символов (модель `gterm`); перенос только по пробелам и символам.
- Тест смешения окна использует шрифт репозитория из `crates/gterm-demo/assets` — та же зависимость тестов от соседнего пакета, что у `gterm` (ADR-0017 О2).
- Коммит не делался.
